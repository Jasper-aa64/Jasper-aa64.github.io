QD 岗位问 Level-2，要的不是交易所协议的每个字段，而是两件事：你真的处理过这些数据，以及你知道哪些地方会让研究侧和实盘算出来不一样。下面按这个深度整理。

## 1. 三类数据

| 数据 | 记了什么 | 量级 |
|---|---|---|
| 快照 | 约每 3 秒一张：十档买卖价量、最新价、高开低收、累计成交笔数、量、金额，委买委卖总量；买一卖一前 50 笔挂单（委托队列） | 全市场一天两千多万条 |
| 逐笔委托 | 每一笔挂单（上海还有撤单） | 一天上亿条 |
| 逐笔成交 | 每一次撮合（深圳还有撤单） | 一天上亿条 |

**快照是结果，逐笔是过程**：快照只告诉你 3 秒后盘口变成什么样，谁主动成交、大单什么时候挂上又撤掉，只有逐笔看得到。Level-1 只有五档快照，没有逐笔。

## 2. 沪深两市的差别

| | 深圳 | 上海 |
|---|---|---|
| 逐笔委托记什么 | 交易所收到的每一笔新委托，原始申报数量；类型分限价、市价、本方最优 | 进入订单簿的部分：立即全部成交的不发，部分成交的只发剩余量；类型分新增、删除 |
| 撤单在哪 | 逐笔成交里，成交类别为“撤销”，价格 0 | 逐笔委托里，类型为删除 |
| 主动方 | 没有标志，比较买卖双方委托序号，大的（后到的）是主动方 | 成交带内外盘标志：B 主动买、S 主动卖、N 未知 |
| 序号 | 频道内消息记录号，委托和成交共用 | 通道内业务序号，委托和成交共用 |

一句话记：**深圳的逐笔委托记“报了什么”，上海记“挂上了什么”**。所以同一个“大单委托”因子，两市要分开写；算撤单，深圳从逐笔成交里取，上海从逐笔委托里取，只订一路就漏一半。

## 3. 序号、回查委托、主动方

- 先后只认序号：时间戳只到毫秒，同一毫秒里一笔委托和它引发的成交常常同时间。同一通道内按序号把委托和成交合成一条流，才是交易所处理的顺序；不同通道的序号不能比。
- 丢包和重复：序号连续，收到 1001、1002、1004 说明 1003 丢了，要补或标记；断线重连后的重发按序号去重。
- 回查委托：深圳成交里的买卖双方委托序号，就是那两笔委托的消息记录号；撤单记录价格是 0，要用非 0 的那个序号查回原委托才知道撤的是哪个价位。上海成交里的买卖方订单号对的是委托的原始订单号，不是业务序号；立即全部成交的单在逐笔委托里查不到。
- 主动方：上海直接看标志；深圳比序号。集合竞价的成交没有主动方，上海标 N，深圳比序号没有意义，算主动买卖量时要把这段剔掉或单独处理。

## 4. 集合竞价

开盘集合竞价 9:15–9:25（9:20 以后不能撤单），这段只收单不成交，9:25 一次撮合，产生一批同一价格、同一时间的成交；9:30 进入连续竞价。收盘集合竞价 14:57–15:00，同样最后一次撮合。深圳的市价单和本方最优委托只在连续竞价出现，9:30 以前没有。写因子时，这几段的成交和普通连续竞价的成交性质不同，要不要算进去、怎么切 bar，得和研究侧约定。

## 5. 写因子时要和研究侧对齐的地方

| 地方 | 会怎么对不上 |
|---|---|
| 累计量相减 | 快照的量、额、笔数是开盘起的累计值。当天第一张，pandas `diff()` 给 NaN，C++ 上一张从 0 起算会得出开盘以来的全部量 |
| 快照不是每 3 秒都有 | 没变化通常不推，切 bar 时空格子用前值补还是留空要约定 |
| 价格和金额 | 价格是放大过的整数，倍数按数据商文档并用真实数据核；有的数据商成交金额是去掉角分的整数元，零股、科创板 201 股这类会少几毛，要准就用价×量 |
| 深圳撤单混在成交里 | 直接用逐笔成交算均价，价格 0、数量非 0 的撤单行会把均价拉低 |
| 时间 | 交易所时间还是本机收到时间；bar 左闭右开还是右闭；集合竞价和午休怎么切 |
| 快照和逐笔对齐 | 两者节拍和时间精度不同，按时间戳把逐笔加到快照时刻不一定等于快照的累计量；严格对齐要用逐笔重建盘口再比 |

## 6. 被问到时怎么讲

实习里我做的是 Level-2 接入：两家数据商的沪深快照、逐笔委托、逐笔成交转成统一结构落盘。能讲的是真实数据核出来的东西，比如价格倍数、深圳委托类别实际只有三种、上海删除记录的两种写法、上海成交金额改成价×量后核到分、序号回退其实是统计脚本太慢导致环被套圈。没做过的是在逐笔上算因子；被问到就说清楚这一点，再讲上面第 3、5 节：如果让我用逐笔算一个因子，取数和对齐会在哪些地方出问题。
