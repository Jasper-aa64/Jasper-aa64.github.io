这一轮的四样东西都在数组上做查询，目标都是把暴力的 $O(n^2)$ 降下来。降得下来，靠的是两种性质：一种是单调性（二分、双指针），一种是能相减的累计量（前缀和、差分）。复杂度放在最前面，因为它决定一道题该往哪个方向想。

## 1. 复杂度：先看数据范围

### 1.1 数据范围反推复杂度

C++ 一秒大约能做 $10^8$ 次简单操作（加法、比较、数组访问）。题目给出 $n$ 的上限，能接受的复杂度也就基本定了：

| $n$ 的上限 | 能接受的复杂度 | 常见做法 |
|---|---|---|
| $20$ 左右 | $O(2^n \cdot n)$ | 枚举子集、状压 DP |
| $500$ | $O(n^3)$ | 区间 DP、Floyd |
| $5000$ | $O(n^2)$ | 二重循环的 DP |
| $2 \times 10^5$ | $O(n \log n)$ | 排序、二分、堆、线段树 |
| $10^7$ | $O(n)$ | 双指针、前缀和、线性筛 |
| $10^{18}$ | $O(\log n)$ 或 $O(\sqrt n)$ | 快速幂、二分答案、数论分块 |

比如 $n$ 到 $2 \times 10^5$，$O(n^2)$ 是 $4 \times 10^{10}$ 次，必然超时，就要往排序、二分、双指针上想。**拿到题先看 $n$：它几乎直接告诉你该用哪一类算法。** 面试也一样，面试官报出数据规模，就是在提示复杂度。

### 1.2 STL 容器的代价

| 操作 | 复杂度 | 坑 |
|---|---|---|
| `vector::push_back` | 均摊 $O(1)$ | 扩容时整体搬家；知道大小就先 `reserve` |
| `sort` | $O(n \log n)$ | 比较函数必须是严格的“小于”，写成 `<=` 会出错，甚至越界崩溃 |
| `map` / `set` 的增删查 | $O(\log n)$ | 红黑树，常数比哈希表大 |
| `unordered_map` 的增删查 | 平均 $O(1)$，最坏 $O(n)$ | Codeforces 上有人专门构造冲突数据，要换自定义哈希 |
| `priority_queue` 的 `push` / `pop` | $O(\log n)$ | 默认是大根堆 |
| `lower_bound` 用在 `vector` 上 | $O(\log n)$ | |
| `std::lower_bound` 用在 `set` 上 | $O(n)$ | `set` 的迭代器不能随机访问，要用成员函数 `s.lower_bound(x)` |

**很多超时不是算法想错了，而是用错了接口。** 表里 `set` 那一条是一个，另外常见的还有两个：

1. **多组数据时每组都 `memset`**
   - **代价**：每组清一个 $10^6$ 的数组，$T$ 组就是 $T \times 10^6$。$T$ 到 $10^4$ 时是 $10^{10}$，必然超时。
   - **改法**：只清这一组用到的前 $n$ 个，比如 `fill(a, a + n + 1, 0)`；或者每组按 $n$ 现开，比如 `vector<int> a(n + 1)`。
2. **输入输出量大时没关同步**
   - **为什么慢**：`cin` / `cout` 默认和 C 的 `scanf` / `printf` 同步，不能自己攒一大块再读写；`cin` 还默认绑着 `cout`，每读一次都先把输出刷出去。
   - **改法**：开头加 `ios::sync_with_stdio(false); cin.tie(nullptr);`。关了同步以后，不要再和 `scanf` / `printf` 混用。
   - **换行**：用 `'\n'`，不用 `endl`。`endl` 每次都会刷新缓冲区。

## 2. 二分：在单调的判定上找边界

### 2.1 一个模板：找第一个为真的位置

二分的前提不是“数组有序”，而是判定单调：有一个判定 `pred(i)`，前面一段全为假，从某个位置起全为真，要找的是第一个为真的位置。在有序数组里找第一个 $\ge t$ 的数，只是 `pred(i) = a[i] >= t` 这一种情况。

```cpp
// 在 [lo, hi) 里找第一个让 pred 为真的位置；全为假时返回 hi
template <class Pred>
long long first_true(long long lo, long long hi, Pred pred) {
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (pred(mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

它为什么对：循环里一直保持两件事，`lo` 左边全为假，`hi` 和它右边全为真（`hi` 一开始在区间外，当它为真）。`mid` 为真，第一个真在 `mid` 或它左边，于是 `hi = mid`；`mid` 为假，第一个真在 `mid` 右边，于是 `lo = mid + 1`。区间每次都缩小，缩到 `lo == hi` 时，这个位置左边全假、它自己为真，正是要找的。全为假时返回 `hi` 的初值，表示“没有”。`mid` 写成 `lo + (hi - lo) / 2`，是为了防止 `lo + hi` 溢出。

**只背这一种写法（左闭右开，找第一个真），别的问法都改写成它：**

- 第一个 $\ge t$：`pred = a[i] >= t`，就是 `lower_bound`；
- 第一个 $> t$：`pred = a[i] > t`，就是 `upper_bound`；
- 最后一个 $\le t$：第一个 $> t$ 的位置减 1；
- $t$ 出现几次：`upper_bound` 减 `lower_bound`。

### 2.2 二分答案：把“求最小”变成“判断行不行”

很多题问“最小的 $x$，使得……能做到”。如果能做到 $x$ 就一定能做到比 $x$ 大的值，那么 `pred(x) = x 能做到` 就是前面全假、后面全真，第一个真就是答案。**二分答案把求最优变成判定可行，而判定通常比直接求最优好写得多。**

例子：有 $n$ 堆香蕉，每小时吃 $k$ 根，要在 $h$ 小时内吃完，求最小的 $k$。速度越快越吃得完，判定是单调的。速度为 $k$ 时，一堆 $p$ 根要 $\lceil p / k \rceil$ 小时，加起来不超过 $h$ 就行：

```cpp
int min_speed(const vector<int>& piles, long long h) {
    auto ok = [&](long long k) {
        long long hours = 0;
        for (int p : piles) hours += (p + k - 1) / k;   // 上取整
        return hours <= h;
    };
    return first_true(1, *max_element(piles.begin(), piles.end()) + 1, ok);
}
```

速度取最大的一堆就一定吃得完，所以上界是它加 1。复杂度 $O(n \log V)$，$V$ 是最大的一堆。

> **认出二分答案的信号**：下面两条同时满足。
>
> - **问法**：题目问“最大值最小是多少”“最小值最大是多少”“最少需要多少”。
> - **好验证**：给定一个答案，判断它行不行很容易。

小数上的二分不用 eps 判断结束，固定循环 100 次：每次区间减半，100 次以后精度远超需要，也不会因为浮点误差死循环。

## 3. 双指针与滑动窗口

### 3.1 什么时候左端点只往右走

枚举所有子数组是 $O(n^2)$。双指针能做到 $O(n)$，前提是：右端点往右走时，合法窗口的左端点不会往左退。这样左端点总共只走 $n$ 步，每个元素进窗口一次、出窗口一次。

这个单调性来自窗口合法性在缩小时能保持。以“窗口里没有重复字符”为例：一个窗口没有重复，它里面更小的窗口也没有。所以右端点往右扩出了重复，只需把左端点往右挪到重复消失为止；之后右端点再往右，左端点也不用回头，因为回头得到的窗口更大，只会更不合法。判断能不能用，就看这个单调性在不在：

> **认出双指针（滑动窗口）的信号**：下面两条同时满足。
>
> - **问法**：求满足某个条件的最长或最短连续子数组、子串。
> - **单调**：合法性随窗口大小单调。求最长时，合法的窗口缩小后还合法；求最短时，合法的窗口扩大后还合法（3.2）。这样左端点只往右走，$O(n)$。

### 3.2 两种写法：最长合法、最短合法

求最长的合法窗口：右端点每扩一格，不合法就缩左端点，缩到合法再记答案。

```cpp
// 最长的无重复字符子串
int longest_unique(const string& s) {
    int cnt[256] = {}, best = 0, l = 0;
    for (int r = 0; r < (int)s.size(); r++) {
        cnt[(unsigned char)s[r]]++;
        while (cnt[(unsigned char)s[r]] > 1) cnt[(unsigned char)s[l++]]--;
        best = max(best, r - l + 1);
    }
    return best;
}
```

求最短的合法窗口：右端点每扩一格，只要还合法，就记答案、缩左端点。

```cpp
// 和至少为 target 的最短子数组，元素都为正
int min_len(int target, const vector<int>& a) {
    int n = a.size(), best = INT_MAX, l = 0;
    long long sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum >= target) {
            best = min(best, r - l + 1);
            sum -= a[l++];
        }
    }
    return best == INT_MAX ? 0 : best;
}
```

第二段依赖元素全为正：这样窗口越大和越大，“和 $\ge$ target”在扩大时保持、在缩小时可能失去，左端点才只往右走。**数组里有负数时，窗口和不再随窗口单调，双指针会给出错的答案**，要换成前缀和加单调队列（A2 讲）。

### 3.3 另一种双指针：有序数组两头往中间夹

在有序数组里找两个数，和为 $t$：左指针在头、右指针在尾，和小了左指针右移，和大了右指针左移。每一步扔掉一个下标，扔掉的那个不可能在解里，所以不会漏掉答案：

- **和大于 $t$ 时可以扔掉 $r$**：剩下的任何 $l' \in [l, r)$ 都有 $a_{l'} \ge a_l$，所以 $a_{l'} + a_r \ge a_l + a_r > t$。$r$ 已经和剩下最小的数配过了还嫌大，和谁配都不行，所以 `r--` 不会丢掉解。
- **和小于 $t$ 时可以扔掉 $l$**：剩下的任何 $r' \in (l, r]$ 都有 $a_l + a_{r'} \le a_l + a_r < t$。$l$ 已经和剩下最大的数配过了还嫌小，所以 `l++` 也不会丢掉解。

三数之和就是枚举第一个数，再对剩下的部分做一次两头夹，$O(n^2)$。

## 4. 前缀和与差分

### 4.1 前缀和：区间和变成两个数相减

令 $S_0 = 0$，$S_i = a_0 + a_1 + \dots + a_{i-1}$，那么区间 $[l, r)$ 的和就是 $S_r - S_l$。预处理 $O(n)$，之后每次询问 $O(1)$。$S$ 比原数组多开一位、区间用左闭右开，$l = 0$ 时就不用特判。

前缀和更大的用处，是把“子数组和”换成“两个前缀之差”，子数组问题于是变成“在前缀数组里找一对 $l < r$”的问题。以“和为 $k$ 的子数组有几个”为例：要数满足 $S_r - S_l = k$ 的对，从左往右扫 $r$，每到一个 $r$，就问前面有几个 $S_l = S_r - k$，用哈希表记每个前缀和出现的次数：

```cpp
long long count_sum_k(const vector<int>& a, long long k) {
    unordered_map<long long, long long> seen{{0, 1}};   // S_0 = 0 先放进去
    long long s = 0, ans = 0;
    for (int x : a) {
        s += x;
        if (auto it = seen.find(s - k); it != seen.end()) ans += it->second;
        seen[s]++;
    }
    return ans;
}
```

`seen` 一开始放一个 0，对应从开头开始的子数组。这里数组可以有负数，滑动窗口却不行。两种做法靠的东西不一样：

1. **滑动窗口靠的是窗口和的单调性**
   - **它要求窗口和随窗口大小单调**：右端点 $r$ 往右扩，窗口和变大；左端点 $l$ 往右缩，窗口和变小。只有元素全为正时，这一条才成立。
   - **单调性让左端点敢只往右走**：窗口和超过目标时把 $l$ 右移，缩小以后和只会变小，一步步逼近目标。被扔掉的左端点配上更靠右的 $r$，和只会更大，不可能是解，所以不会漏（3.2）。
   - **有负数时，扔掉左端点这一步会出错**：后面来的负数能把和拉回来，被扔掉的左端点其实还能用。
   - **例子**：$a = [3, -2, 1]$，找和为 2 的子数组，答案是整个数组。滑动窗口在 $r = 0$ 时看到和是 3，比 2 大，就把 3 扔掉了；它不知道后面的 $-2$ 会把和拉回到 2，于是漏掉了这个解。
2. **前缀和加哈希表靠前缀和把问题转成一个等式**
   - **前缀和把“找子数组”转成“找一个前缀和”**：令 $S_i = a_0 + a_1 + \dots + a_{i-1}$，$[l, r)$ 的和就是 $S_r - S_l$。问“哪一段的和等于 $k$”，就变成问“前面有没有一个 $S_l$ 等于 $S_r - k$”：

     $$S_r - S_l = k \iff S_l = S_r - k$$

   - **扫右端点时查前面有几个合适的左端点**：哈希表记下前面每个前缀和出现了几次，每到一个 $r$，查一次 $S_r - k$ 出现的次数，$O(1)$。
   - **它只看等式成立不成立**：数值变大还是变小、有没有负数、有没有序，都不影响。
   - **例子**：还是 $a = [3, -2, 1]$、$k = 2$。前缀和是 $0, 3, 1, 2$。扫到最后 $S_3 = 2$ 时，要找 $S_l = 0$，表里有一个（$S_0$），数到 1 个，就是整个数组。
   - **它只能回答写得成等式的问题**：问“和等于 $k$”可以；问“和至少为 $k$ 的最短子数组”是不等式，有负数时要换成前缀和加单调队列（A2）。

> **前缀和加哈希表，还是滑动窗口**：先看数组里有没有负数。
>
> - **有负数时用前缀和加哈希表**：滑动窗口靠的单调性没了，扔掉左端点会漏解。
> - **全为正时两种都能用**：滑动窗口只要 $O(1)$ 的额外空间，前缀和加哈希表要 $O(n)$。

二维前缀和：$S_{i,j}$ 是左上角 $i$ 行 $j$ 列那块矩形的和。按容斥，

$$S_{i+1,j+1} = S_{i,j+1} + S_{i+1,j} - S_{i,j} + a_{i,j}$$

行 $[r_1, r_2)$、列 $[c_1, c_2)$ 的子矩形和是

$$S_{r_2,c_2} - S_{r_1,c_2} - S_{r_2,c_1} + S_{r_1,c_1}$$

```cpp
struct Prefix2D {
    vector<vector<long long>> S;
    Prefix2D(const vector<vector<int>>& a) {
        int n = a.size(), m = a[0].size();
        S.assign(n + 1, vector<long long>(m + 1, 0));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                S[i + 1][j + 1] = S[i][j + 1] + S[i + 1][j] - S[i][j] + a[i][j];
    }
    long long sum(int r1, int c1, int r2, int c2) const {   // 行 [r1, r2)、列 [c1, c2)
        return S[r2][c2] - S[r1][c2] - S[r2][c1] + S[r1][c1];
    }
};
```

### 4.2 差分：区间加变成改两个点

差分是前缀和的反操作：$d_i = a_i - a_{i-1}$（$a_{-1}$ 当作 0）。给 $[l, r)$ 里每个数都加 $v$，相邻两数的差只在两处变了：$d_l$ 多了 $v$，$d_r$ 少了 $v$。所有区间加做完，对 $d$ 求一遍前缀和，就还原出 $a$。$q$ 次区间加因此从 $O(nq)$ 降到 $O(n + q)$。

```cpp
// 每个操作 {l, r, v}：给 [l, r) 加 v
vector<long long> apply_adds(int n, const vector<array<int, 3>>& ops) {
    vector<long long> d(n + 1, 0);
    for (auto [l, r, v] : ops) {
        d[l] += v;
        d[r] -= v;
    }
    vector<long long> a(n);
    long long run = 0;
    for (int i = 0; i < n; i++) a[i] = run += d[i];
    return a;
}
```

**前缀和与差分互为逆运算：一个把点累成区间，一个把区间拆回点。** 所以选哪个看操作：

> **差分、前缀和，还是树**：看修改和查询怎么来。
>
> - **区间加、最后才查**：用差分。
> - **数组不变、反复查区间和**：用前缀和。
> - **修改和查询穿插着来**：两者都不够，要上树状数组或线段树（B1）。

二维差分同理：给一个子矩形加 $v$，改四个角，左上 $+v$、右上外侧 $-v$、左下外侧 $-v$、右下外侧 $+v$，最后做一遍二维前缀和还原。

### 练习 1：LC 34 两个边界都用“第一个为真”

- **题意**：升序数组里找 target 第一次和最后一次出现的位置，没有就返回 `[-1, -1]`。$n \le 10^5$，要求 $O(\log n)$。
- **两个边界都写成“第一个为真”**：左边界是第一个 $\ge t$ 的位置，右边界是第一个 $> t$ 的位置减 1。
- **最后检查左边界**：$L$ 越界，或者 `a[L]` 不等于 $t$，说明 $t$ 不在数组里。

```cpp
vector<int> searchRange(vector<int>& a,int t){
    auto ft=[&](auto p){int l=0,r=a.size();while(l<r){int m=(l+r)/2;if(p(a[m]))r=m;else l=m+1;}return l;};
    int L=ft([&](int x){return x>=t;}),R=ft([&](int x){return x>t;})-1;
    if(L==(int)a.size()||a[L]!=t)return {-1,-1};
    return {L,R};
}
```

- **复杂度**：两次二分，$O(\log n)$。
- **坑**：右边界不用另写一套“最后一个为真”，第一个 $> t$ 减 1 就是。模板只背 2.1 那一种。

### 练习 2：LC 1011 二分运力，判定用贪心装满

- **题意**：包裹按顺序装船，每天装的总重不超过运力，要在 D 天内送完，求最小运力。$n \le 5 \times 10^4$，每件 $\le 500$。
- **运力越大越容易送完，所以“能送完”关于运力单调**：找第一个能送完的运力（2.2）。
- **判定用贪心**：按顺序装，装不下就开新的一天，数出要几天，和 D 比。
- **上下界**：下界是最重的那件，因为一天至少要装下它；上界是总重，一天送完。

```cpp
int shipWithinDays(vector<int>& w,int D){
    int l=*max_element(w.begin(),w.end()),r=accumulate(w.begin(),w.end(),0);
    auto ok=[&](int c){int d=1,s=0;for(int x:w){if(s+x>c)d++,s=0;s+=x;}return d<=D;};
    while(l<r){int m=(l+r)/2;if(ok(m))r=m;else l=m+1;}
    return l;
}
```

- **复杂度**：$O(n \log \sum w)$。
- **坑**：下界不能从 0 或 1 开始。运力比某件还小时，贪心照样开新的一天把它塞进去，算出的天数偏少，答案就偏小。

### 练习 3：LC 1004 最长合法窗口，合法是窗口里 0 不超过 k 个

- **题意**：数组只含 0 和 1，最多把 k 个 0 改成 1，求最长的连续全 1 子数组。$n \le 10^5$。
- **先把“合法”说清楚**：改哪几个 0 不用真去挑，窗口里的 0 全改掉就行，所以合法就是窗口里 0 的个数 $\le k$。
- **合法窗口缩小后还是合法**：里面的 0 只会更少。这正是 3.2“最长合法窗口”要的单调性，左端点只往右走。

```cpp
int longestOnes(vector<int>& a,int k){
    int z=0,best=0;
    for(int l=0,r=0;r<(int)a.size();r++){
        z+=a[r]==0;
        while(z>k)z-=a[l++]==0;      // 缩到合法
        best=max(best,r-l+1);
    }
    return best;
}
```

- **复杂度**：每个元素进出窗口各一次，$O(n)$。
- **坑**：$k = 0$ 不用特判，窗口自然只停在全 1 段上。

### 练习 4：LC 974 前缀和按余数分组，同组任选两个

- **题意**：求有多少个非空连续子数组的和能被 k 整除。$n \le 3 \times 10^4$，元素可以是负数，$2 \le k \le 10^4$。
- **前缀和把子数组和变成两个数相减**：子数组 $(l, r]$ 的和是 $S_r - S_l$，它能被 k 整除，当且仅当 $S_r \bmod k = S_l \bmod k$。
- **所以题目变成数同余的前缀对**：从左往右扫，每到一个 $r$，前面有几个同余的前缀，就新凑出几个子数组。
- **滑动窗口用不了，因为“能被整除”不单调**：`[1]` 不行，`[1, 4]` 可以（k = 5），`[1, 4, 1]` 又不行，窗口没法决定该缩还是该扩。

```cpp
int subarraysDivByK(vector<int>& a,int k){
    vector<int> c(k);c[0]=1;            // 空前缀 S_0 = 0
    int s=0,ans=0;
    for(int x:a){s=((s+x)%k+k)%k;ans+=c[s]++;}
    return ans;
}
```

- **复杂度**：$O(n)$。余数只有 k 种，用数组计数，不用哈希表。
- **坑**：
  - **C++ 里负数取模是负的**：`-2 % 5 == -2`，拿来当下标会越界；改用哈希表的话，−2 和 3 本该是同一个余数，会被当成两组。所以写成 `(s % k + k) % k`。
  - **`c[0] = 1` 不能漏**：它就是空前缀，从开头起的子数组都配它。输入 `[5]`、k = 5，漏了会输出 0，正确答案是 1。
  - **先加 `c[s]` 再自增**：只和前面的前缀配对，不会把自己和自己配成空子数组。

### 练习 5：LC 1094 每单是一次区间加，用差分

- **题意**：车只往东开，每单是 `[人数, 上车点, 下车点]`，问车上人数会不会超过 capacity。最多 1000 单，站点在 $[0, 1000]$。
- **每一单都是给一段区间里每个点加同一个人数**：上车点 $+p$，下车点 $-p$，最后做一遍前缀和，就是每个位置车上的人数（4.2）。
- **区间是左闭右开 $[\text{from}, \text{to})$**：乘客在 to 这一站已经下车，不占座。

```cpp
bool carPooling(vector<vector<int>>& t,int cap){
    int d[1001]={};
    for(auto&v:t)d[v[1]]+=v[0],d[v[2]]-=v[0];
    for(int i=0,c=0;i<=1000;i++)if((c+=d[i])>cap)return false;
    return true;
}
```

- **复杂度**：$O(\text{单数} + \text{站点范围})$。
- **坑**：
  - **写成 `d[to + 1] -= p` 就成了闭区间**：在 to 那一站多算一批人。比如 `[[2,1,5],[3,5,7]]`、capacity = 3：第一单在站点 5 已经下车，答案是 true；写成闭区间会在站点 5 算出 5 人，返回 false。
  - **坐标到 $10^9$ 时开不了数组**：把所有端点排序后扫一遍（扫描线），思路不变。

### 练习 6：LC 410 “最大值最小”，二分这个最大值

- **题意**：把数组切成 k 段连续的非空子数组，让各段和的最大值最小。$n \le 1000$，元素 $\le 10^6$，$k \le \min(50, n)$。
- **给定上限 m，能不能切成不超过 k 段、每段和都不超过 m**：m 越大越容易做到，所以“可行”关于 m 单调，找第一个可行的 m。
- **判定用贪心**：从左往右装，装不下就开新的一段，数出最少要几段，和 k 比。
- **上下界**：下界是最大的那个元素，上界是总和。

```cpp
int splitArray(vector<int>& a,int k){
    long long l=*max_element(a.begin(),a.end()),r=accumulate(a.begin(),a.end(),0LL);
    auto ok=[&](long long m){int c=1;long long s=0;for(int x:a){if(s+x>m)c++,s=0;s+=x;}return c<=k;};
    while(l<r){long long m=(l+r)/2;if(ok(m))r=m;else l=m+1;}
    return l;
}
```

- **复杂度**：$O(n \log \sum a)$。
- **坑**：
  - **总和能到 $10^9$**：用 `long long`。
  - **下界必须是最大元素**：和练习 2 一样，从 0 开始时单个元素就超过 m，贪心会算错段数。

### 练习 7：LC 76 最短合法窗口，用一个缺口计数 O(1) 判合法

- **题意**：在 s 里找最短的子串，让它包含 t 的所有字符，重复的字符要够数。$|s|, |t| \le 10^5$。
- **窗口合法以后，再往右扩大还是合法**：所以对每个右端点，左端点只往右走；求最短，就在合法时尽量收缩左边（3.2）。
- **难点是 $O(1)$ 判断窗口合法**：`need[c]` 记还差几个 c，`miss` 记总共还差几个字符。
  - **右端点进来时 `need` 减 1**：减之前大于 0，说明补上了一个缺口，`miss--`。
  - **左端点出去时 `need` 加 1**：加完大于 0，说明出现了新缺口，`miss++`。
  - **`miss == 0` 就是合法**。

```cpp
string minWindow(string s,string t){
    int need[128]={},miss=t.size(),L=0,len=INT_MAX;
    for(char c:t)need[c]++;
    for(int l=0,r=0;r<(int)s.size();r++){
        if(need[s[r]]-->0)miss--;
        while(!miss){
            if(r-l+1<len)len=r-l+1,L=l;
            if(++need[s[l++]]>0)miss++;
        }
    }
    return len==INT_MAX?"":s.substr(L,len);
}
```

- **复杂度**：$O(|s| + |t|)$，每个下标进出窗口各一次。
- **坑**：
  - **窗口里多出来的字符，`need` 会变成负数**：这正是要的效果，它出去时先加回到 0，不会误报缺口。
  - **更新答案要在 `while (!miss)` 里面、移动左端点之前**。

### 练习 8：洛谷 P3397 二维差分，改四个角

- **题意**：$n \times n$ 的格子，m 次操作，每次给一个矩形里的格子全部加 1，最后输出整个格子。$n, m \le 1000$。
- **每次暴力加是 $O(n^2)$**：m 次一共 $10^9$，太慢。
- **差分把每次操作变成改四个角，$O(1)$**：最后做一遍二维前缀和还原（4.2 末尾）。
  - **左上角 $(a, b)$ 加 1**。
  - **右上角外 $(a, e+1)$ 和左下角外 $(c+1, b)$ 各减 1**。
  - **右下角外 $(c+1, e+1)$ 加 1**：它被前面两次各减了一次，要补回来。

```cpp
#include<bits/stdc++.h>
using namespace std;
int d[1005][1005];
int main(){
    int n,m;scanf("%d%d",&n,&m);
    while(m--){
        int a,b,c,e;scanf("%d%d%d%d",&a,&b,&c,&e);
        d[a][b]++,d[a][e+1]--,d[c+1][b]--,d[c+1][e+1]++;
    }
    for(int i=1;i<=n;i++,puts(""))for(int j=1;j<=n;j++){
        d[i][j]+=d[i-1][j]+d[i][j-1]-d[i-1][j-1];
        printf("%d ",d[i][j]);
    }
}
```

- **复杂度**：$O(m + n^2)$。
- **坑**：数组至少开到 $n + 2$，因为 $c+1$、$e+1$ 会到 $n+1$。
