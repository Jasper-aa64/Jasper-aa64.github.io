> 线性代数的本质：研究对加法和数乘封闭的集合，以及保持加法和数乘的映射。

前一种叫线性空间，后一种就是矩阵。赛场上的矩阵快速幂、高斯消元、线性基、行列式，都是在这两样东西上问不同的问题。这一篇先把模型立住：空间和基（第 1、2 节）、怎么求基（第 3 节）、换一个数域会变什么（第 4 节）、矩阵和解方程（第 5、6 节）、行列式（第 7 节），最后对照到具体工具上（第 8 节）。

## 1. 线性空间：相加、乘系数，都跑不出去

一个集合里的元素（叫向量）两两相加、乘上任意系数，结果还在集合里，这个集合就是**线性空间**。它一定含零向量，因为任何向量乘 0 都得到它。

系数从哪里取，叫**数域**。数域是一套加减乘除都能做（除数非 0）的运算规则。赛场上用到三种：

| 数域 | 系数 | 向量是什么 | 典型题 |
| --- | --- | --- | --- |
| 实数 $\mathbb{R}$ | 任意实数 | 实数坐标 | 期望有环的方程组、几何 |
| 模质数 $\mathbb{F}_p$ | $0 \sim p-1$，除法换成乘逆元 | 模 $p$ 的坐标 | 计数、模意义下解方程、行列式 |
| GF(2) | 只有 0、1 | 0/1 串，也就是一个整数的二进制 | 异或、开关灯 |

这一篇的定义和结论只用到加减乘除，所以在三种数域上一字不改地成立。

例子和反例：

- $\mathbb{R}^2$ 里过原点的直线 $\{(t, 2t)\}$ 是线性空间：两个点相加、乘一个数都还在线上。
- 不过原点的直线不是，乘 0 就到了原点；第一象限也不是，乘 $-1$ 就出去了。
- GF(2) 里 $\{0, 3, 5, 6\}$ 是线性空间，任意两个异或都还在里面；$\{0, 1, 2\}$ 不是，因为 $1 \oplus 2 = 3$。

## 2. 基、维数、秩：用最少的向量描述整个空间

一组向量所有的线性组合 $k_1 v_1 + k_2 v_2 + \cdots + k_n v_n$ 组成的集合，叫它们**张成的空间**，它自动是一个线性空间。如果其中某个向量能被其余的组合出来，它就是多余的，删掉不改变张成的空间。删到不能再删，剩下的向量**线性无关**（只有系数全 0 的组合才等于零向量），它们是这个空间的一组**基**，个数叫空间的**维数**。一组向量张成的空间的维数，叫这组向量的**秩**。

基有两条性质，后面反复用到：

- **表示唯一**：空间里每个元素在基上的系数只有一种。假如有两种，相减就得到基的一个系数不全为 0、结果却等于零向量的组合，和线性无关矛盾。
- **元素个数由维数决定**：$r$ 维空间的元素，就是 $r$ 个系数各取一个值。实数上有无穷多个，模 $p$ 下有 $p^r$ 个，GF(2) 上有 $2^r$ 个。

## 3. 求基：高斯消元把多余的向量消成 0

求基就是把“删掉多余的向量”做成算法，做法是高斯消元。

1. 把 $n$ 个向量排成矩阵的 $n$ 行。
2. 从第一列开始，找一个这一列非零的行作主元行，换到上面，用它把下面各行这一列消成 0：第 $j$ 行减去主元行的 $k$ 倍，$k$ 取第 $j$ 行这一列的值除以主元。
3. 一列一列做完，非零的行就是一组基，非零行的个数就是秩。

为什么对：

- 消元只是把一行换成它和别的行的组合，不改变张成的空间。
- 多余的向量能被别的行组合出来，所以会被消成全 0 行。
- 消完剩下的非零行，每行的主元列在它下面的行里都是 0，谁也组合不出谁，所以线性无关。

例子（实数）：$u = (1, 1, 0)$、$v = (0, 1, 1)$、$w = (1, 2, 1)$。

- 第 1 列：$u$ 作主元行，$w$ 减去 $u$ 得 $(0, 1, 1)$。
- 第 2 列：$v$ 作主元行，$w$ 再减去 $v$ 得 $(0, 0, 0)$。

$w$ 被消成 0，因为 $w = u + v$。基是 $\{u, v\}$，秩是 2。

## 4. 换一个数域：同一组 0/1 向量，秩会变

> 换数域的本质：换的是运算规则，不是向量里存的数。

实数里 $1 + 1 = 2$，GF(2) 里 $1 + 1 = 0$。只包含 0、1 的向量放在实数里，加起来会出现 2，乘系数会出现 $-1$、$\frac12$，跑出 0/1 的范围。GF(2) 是另一套运算规则：只有 0 和 1，加法逐位相加再模 2，也就是异或。同样写成 $(1, 0, 1)$，两边算出来的东西不一样。

### 4.1 例子：秩 3 还是秩 2

三个向量 $u = (1, 1, 0)$、$v = (0, 1, 1)$、$w = (1, 0, 1)$：

| | 实数 $\mathbb{R}$ | GF(2) |
| --- | --- | --- |
| $u + v$ | $(1, 2, 1)$ | $(1, 0, 1) = w$ |
| $u + v + w$ | $(2, 2, 2)$，不是零向量 | $(0, 0, 0)$ |
| 线性无关吗 | 无关，秩 3 | 相关，$w = u + v$，秩 2 |
| 张成的空间 | 整个 $\mathbb{R}^3$，无穷多个点 | 4 个点：$000, 110, 011, 101$ |

写成整数就是 6、3、5：$6 \oplus 3 = 5$，所以插线性基时 5 会被消成 0；实数里却找不到系数把它们组合成零向量。

### 4.2 换的只是运算表，概念和流程照搬

| | 实数 | GF(2) |
| --- | --- | --- |
| 系数 | 任意实数 | 只有 0、1 |
| 加法 | $1 + 1 = 2$ | $1 + 1 = 0$，即异或 |
| 减法 | 普通减法 | 和加法相同，$-1 = 1$ |
| 消元一步 | 第 $j$ 行减去主元行的 $k$ 倍 | 第 $j$ 行异或主元行 |
| 线性无关 | 只有系数全 0 的组合等于零向量 | 没有非空子集异或为 0 |
| $r$ 维空间多大 | 无穷 | $2^r$ |

线性空间、基、秩、张成、核的定义只用到“加法”和“乘系数”，换了运算表照样成立。高斯消元也照搬：GF(2) 里系数只有 1，减去 1 倍等于加上 1 倍，“减去 $k$ 倍”就变成“异或”。所以不要把 GF(2) 想成“实数向量碰巧只含 0 和 1”，它是一个新的数域，在这个数域上 0/1 串是向量，异或是向量加法。

### 4.3 GF(2) 上一个基向量就是一个整数

一个 0/1 串正好用一个整数的二进制存下，求基的高斯消元就变成了线性基：

| | 普通线性代数 | 线性基 |
| --- | --- | --- |
| 一个向量 | 一组坐标，比如 $(1, 0, 1)$ | 一个整数，比如 $5 = 101_2$ |
| 向量相加 | 逐分量相加 | `x ^ y` |
| 基 | 消元后的非零行 | 数组 `b[0..59]` 里非零的数 |
| 主元 | 每个非零行第一个非零的列 | `b[i]` 的最高位恰好是第 $i$ 位 |

线性基消元的顺序和第 3 节不同：不是拿到整个矩阵再一列列消，而是**来一个数消一个数**。插入 $x$ 时从高位往低位看，第 $i$ 位是 1 而 `b[i]` 有数，就 `x ^= b[i]` 把这一位消掉，这是一次行变换；`b[i]` 空着就把 $x$ 存进去，它成为一个新的基向量；一路被消成 0，说明 $x$ 能被已有的基异或出来，是多余的。

例子：依次插入 $3 = 011_2$、$5 = 101_2$、$6 = 110_2$。

- 插 3：最高位是第 1 位，`b[1]` 空着，存入，`b[1] = 011`。
- 插 5：最高位是第 2 位，`b[2]` 空着，存入，`b[2] = 101`。
- 插 6：第 2 位是 1，异或 `b[2]` 得 $110 \oplus 101 = 011$；第 1 位是 1，异或 `b[1]` 得 $011 \oplus 011 = 000$。被消成 0，说明 $6 = 3 \oplus 5$ 是多余的。

最后基是 $\{3, 5\}$，秩是 2，能异或出 $2^2 = 4$ 个值 $\{0, 3, 5, 6\}$，正是第 1 节里那个线性空间。代码、计数和最大值见 [L2 线性基](/zh/algo/l2-xor-basis/)。

### 4.4 模 2 高斯消元和线性基：同一件事，矩阵方向不同

> 模 2 高斯消元和线性基的本质：都是 GF(2) 上的消元，差在把数排成行还是排成列。

同一个问题两种写法：6、3、5 选一个子集，异或能不能得到 6，有几种选法？

- **线性基**：依次插入 $6 = 110_2$、$3 = 011_2$、$5 = 101_2$，再查 6。插完秩 $r = 2$，6 能异或出来，选法有 $2^{n-r} = 2^{3-2} = 2$ 种。
- **模 2 方程组**：设 $x_i \in \{0, 1\}$ 表示第 $i$ 个数选不选，每一位写一个方程，$x_1 \cdot 110 \oplus x_2 \cdot 011 \oplus x_3 \cdot 101 = 110$。这就是 $Ax = b$：矩阵 $A$ 的**列**是 6、3、5，$b = 110$，3 个方程 3 个未知数。消元后有一个自由元，解是 $(1, 0, 0)$ 和 $(0, 1, 1)$，正好 2 个。

所以“一组数的子集能不能异或出 $v$”，就是“以这些数为列的 0/1 矩阵 $Ax = v$ 有没有解”。线性基把数当行来消，求的是这些数张成的空间（行空间）；方程组问的是 $v$ 在不在 $A$ 的列空间里，也就是第 6 节的“$b$ 在不在像里”。两边是同一组数，行秩等于列秩，所以 $2^{n-r}$ 两边算出来一样：线性基里插入失败的数，就是方程组里的自由元。

两者的区别在用法上：

| | 模 2 高斯消元（01 矩阵） | 线性基 |
| --- | --- | --- |
| 题目给的 | 一个方程组，比如开关灯：每个开关是一个未知数，每盏灯是一个方程 | 一组数，问子集异或能得到什么 |
| 一个数在矩阵里是 | 一列（一个未知数的系数） | 一行，插入时消它 |
| 关心什么 | 解：哪些 $x_i$ 取 1，自由元有几个 | 张成的空间：能得到哪些值、最大值、第 $k$ 小 |
| 消元方式 | 拿到整个矩阵一次消完，离线 | 来一个数消一个，在线 |
| 规模 | 未知数和方程可以到几千，每行存成 bitset，$O(n^3 / 64)$ | 每个数最多 60 位，矩阵只有 60 列，插入一次 $O(60)$ |
| 能不能给出具体选法 | 能，解向量就是选法 | 默认不能，`b[i]` 只存消完的结果；要选法就给每个 `b[i]` 配一个掩码，记它由哪些原数异或而来 |

题目是“给一组数，问子集异或”，用线性基；题目是“给一堆约束，求每个变量取 0 还是 1”（开关灯、异或方程组），用模 2 高斯消元配 bitset。

**三层关系**：模 2 是规则，消元是动作，线性基是消元的结果存成的数据结构。

| 层 | 是什么 | 类比 |
| --- | --- | --- |
| 模 2 | $1 + 1 = 0$ 的运算规则，即异或 | 比较大小的规则 |
| 高斯消元 | 在这个规则下把多余的向量消成 0 | 排序这个动作 |
| 线性基 | 消完留下的 $b[0..59]$，在线维护 | 排完序的有序结构 |

### 4.5 GF(2) 的几何图像：超立方体的顶点

> GF(2) 里线性空间的本质：超立方体顶点中，对异或封闭的一个子集。

实数里张成空间是“直线、平面、立体”，一个线性无关的向量多一维，线性相关的向量落在已有的空间里，维数不变。GF(2) 里系数只有 0 和 1，没有中间的点，空间是有限个点。

**全空间是超立方体的顶点。** $n$ 位的 0/1 串一共 $2^n$ 个，每个是一个顶点，两个串只差一位就连一条边：

| 位数 | 点数 | 形状 |
| --- | --- | --- |
| 2 | 4 | 正方形 |
| 3 | 8 | 立方体 |
| 4 | 16 | 四维超立方体 |
| 60 | $2^{60}$ | 画不出来，规则一样 |

**插入一个数，空间长一维。** 依次插入 $6, 3, 5, 1$（3 位）：

| 插入 | 能异或出的值 | 维数 | 发生了什么 |
| --- | --- | --- | --- |
| $6 = 110$ | $\{000, 110\}$ | 1 | 2 个点 |
| $3 = 011$ | $\{000, 110, 011, 101\}$ | 2 | 4 个点 |
| $5 = 101$ | 不变 | 2 | 5 已在里面，线性相关，被消成 0 |
| $1 = 001$ | 全部 8 个 | 3 | 整个立方体 |

多一维，能得到的值翻一倍，因为新向量可以选或不选：$2 \to 4 \to 8$。插入成功是维数加 1，插入失败是新数落在已有空间里，空间不变。`b` 里的数是这个空间的一组“坐标轴”，个数是维数 $r$，能得到的值是 $2^r$ 个点。

**子空间不一定方正。** 3 位立方体里维数为 1、2 的子空间有这几种：

| 维数 | 例子 | 形状 |
| --- | --- | --- |
| 1 | $\{000, 111\}$ | 一条体对角线 |
| 2 | $\{000, 001, 010, 011\}$ | 立方体的一个面 |
| 2 | $\{000, 110, 011, 101\}$ | 正四面体：4 个含偶数个 1 的顶点，不是任何一个面 |

判断一个点集是不是空间，只看一件事：任取两个点异或后还在集合里，且含 0。比如 $110 \oplus 011 = 101$ 在里面，所以第三行封闭。

**解集是平移，不是空间。** 方程组 $Ax = b$ 的未知数 $x$ 也是 0/1 串，解活在 $x$ 的空间里。以 $6, 3, 5$ 为 $A$ 的列：

- $b = 0$ 的解（核）是 $\{000, 111\}$，因为 $6 \oplus 3 \oplus 5 = 0$。它含 0（什么都不选），对异或封闭，是 $x$ 空间里的一条体对角线，是空间。
- $b = 110$ 的解是 $\{100, 011\}$，即只选 6，或者选 3 和 5。$x = 000$ 得到的是 0 而不是 110，所以它不含 0，不是空间。它等于 $100 \oplus \{000, 111\}$：一个特解异或整个核。

一般地，$Ax = b$ 有解时解集是 $x_0 + \ker A$，任意两个解异或后落在核里，大小 $2^{n-r}$；$b$ 不在像里，就没有解。

值空间里也有对应的图：像是 $\{000, 110, 011, 101\}$，剩下的 4 个顶点 $\{100, 010, 111, 001\}$ 是它的平移，不含 0。立方体的 8 个顶点正好分成这两个正四面体，$b$ 落在前一个里有解，落在后一个里无解。

**换数域，图像还在。** $\text{GF}(3)^2$ 有 9 个点，是 3×3 的网格，上下、左右首尾相连；一个一维子空间是过原点的一条线，有 3 个点。竞赛里基本只用 GF(2) 和模素数的 $\text{GF}(p)$。

## 5. 矩阵就是线性映射

$m \times n$ 的矩阵 $A$ 把 $n$ 维向量 $x$ 变成 $m$ 维向量 $Ax$，并且保持加法和数乘：$A(x + y) = Ax + Ay$，$A(kx) = k \cdot Ax$。保持这两种运算的映射叫**线性映射**。反过来，每个线性映射都能写成一个矩阵：第 $j$ 列放第 $j$ 个单位向量被映到哪里。所以矩阵和线性映射是同一个东西。

由此有两个读法：

- **矩阵乘法是映射的复合**：$(AB)x = A(Bx)$，先做 $B$ 再做 $A$。映射的复合天然满足结合律，矩阵快速幂靠的就是这一点。
- **$Ax$ 是 $A$ 的各列的线性组合**，系数是 $x$ 的各个分量：$Ax = x_1 \cdot (\text{第 1 列}) + \cdots + x_n \cdot (\text{第 n 列})$。所以 $A$ 能到达的全部结果，是它的列张成的空间。

## 6. 像和核：解方程的全部结论

一个线性映射 $A$ 带着两个空间：

- **像**（也叫列空间）：所有能到达的 $Ax$，维数等于 $A$ 的秩 $r$。
- **核**：被 $A$ 送到零向量的所有 $x$，也就是齐次方程组 $Ax = 0$ 的全部解。

两者由**秩-零化度定理**连在一起：核的维数等于 $n - r$，$n$ 是未知数的个数。可以这样理解：$x$ 有 $n$ 个自由度，其中 $r$ 个决定结果落在像里的哪个位置，剩下 $n - r$ 个怎么变都不影响结果，这 $n - r$ 个方向就是核。

解方程组 $Ax = b$ 的结论全从这里来：

- **有没有解**：有解当且仅当 $b$ 在像里。消元后出现“$0 = $ 非零数”的行，就是 $b$ 不在像里。
- **解长什么样**：任取一个解 $x_0$，全部解就是 $x_0$ 加上核里的任意向量。两个解相减，$A(x_1 - x_0) = b - b = 0$，差一定在核里。
- **有几个解**：和核一样多。核是 $n - r$ 维，所以模 $p$ 下有 $p^{n-r}$ 个解；$n - r$ 就是消元后自由元的个数。

线性基里“每个能异或出的值都恰好由 $2^{n-r}$ 个子集得到”是同一个结论：把选法写成 $x \in \{0, 1\}^n$，“选法到异或和”是 GF(2) 上的线性映射，像就是能异或出的值，有 $2^r$ 个；异或出同一个值的选法是核的一次平移，有 $2^{n-r}$ 个。

## 7. 行列式：映射有没有把空间压扁

方阵 $A$ 的行列式 $\det A$，在实数上是这个映射把体积放大的倍数，符号表示有没有翻转方向。$\det A = 0$ 说明 $A$ 把 $n$ 维空间压到了更低的维数，必然有非零向量被送到零向量。所以下面几条说的是同一件事：

- $\det A \ne 0$；
- 秩等于 $n$；
- 核里只有零向量；
- 对任意 $b$，$Ax = b$ 恰好有一个解；
- $A$ 可逆。

计数题用的是行列式的另一个写法：$\det A = \sum_{\sigma} \operatorname{sgn}(\sigma) \prod_{i} A_{i, \sigma(i)}$，对所有排列 $\sigma$ 带符号求和。矩阵树定理和 LGV 引理都是构造一个矩阵，让这个求和恰好数出要的方案。

| BM | 固定的线性映射反复作用产生的数列，满足一个阶数不超过维数的线性递推 |
| 高斯消元 | 求秩，判断 $b$ 在不在像里，数核的维数（自由元个数）。写法和例题见 [L3](/zh/algo/l3-gaussian-elimination/) |
| 线性基 | 在 GF(2) 上一边插入一边求张成空间的基 |
| 行列式 | 映射可不可逆，以及用带符号的排列求和来计数 |

[L2 线性基](/zh/algo/l2-xor-basis/)里每一节对应的概念：

| 普通线性代数 | 线性基里的对应 | L2 的哪一节 |
| --- | --- | --- |
| 线性空间 | 任选子集能异或出的全部值 | 1.1、1.2 |
| 基、秩 | `b` 数组里非零的数，个数 $r \le 60$ | 2.1 |
| 高斯消元求基 | 插入：来一个数消一个数 | 2.1 到 2.3 |
| 表示唯一、$r$ 维有 $2^r$ 个元素 | 不同的异或值有 $2^r$ 个 | 3.1 |
| 核的维数 $n - r$ | 每个值由 $2^{n-r}$ 个子集得到 | 3.2 |
| 简化行阶梯形 | 规范化，求第 $k$ 小 | 4.2、4.3 |
