> 期望的本质：按概率加权的平均值，而且对加法线性，总量的期望等于各部分期望之和。

随机打乱一排水晶，平均能分成几段同色块？

- **直接求分布做不动**：$m$ 颗水晶有 $m!$ 种排法，“恰好分成 $j$ 段”的概率没有好用的式子。
- **但平均段数不需要分布**：段数 = 1 + 相邻两颗颜色不同的次数，每一对相邻的“颜色不同”是 0 或 1，平均值就是它的概率，加起来就是答案。
- **这一步靠的是期望的线性性**：和的期望等于期望的和，不要求各部分独立。期望题的第一件事就是找这样的拆法，拆不开再设状态写方程，状态有环再解方程组。

这一篇先讲期望是什么、为什么能拆（第 1 节），再分类讲能解决哪些问题（第 2 节），然后按方法讲：拆成指示变量（第 3 节）、分布函数（第 4 节）、从终点往回推的期望 DP（第 5 节）、有环时列方程（第 6 节）、整体一起变时找势能（第 7 节）。每一节后面跟例题。有环的方程组怎么解见 [L2 高斯消元](/zh/algo/l2-gaussian-elimination/)。

## 1. 期望是什么、为什么能拆

### 1.1 期望：按概率加权的平均

**随机变量 $X$ 的期望是它每个取值乘上取到这个值的概率，再加起来。**

1. **随机变量是“随机实验的结果对应的一个数”**
   - **它把每种结果映射成一个数**：掷两次骰子，“点数之和”“最大点数”“有没有掷出 6”都是随机变量。
   - **它的分布是每个取值的概率**：$P(X = x)$。
2. **期望就是加权平均**
   - **定义**：$E[X] = \sum_x x \cdot P(X = x)$。
   - **含义**：把实验独立重复很多次，$X$ 的平均值会趋近 $E[X]$。
   - **例子**：一枚骰子 $E[X] = \frac{1 + 2 + \cdots + 6}{6} = 3.5$。

### 1.2 线性性：和的期望等于期望的和

**$E[X + Y] = E[X] + E[Y]$ 对任意两个随机变量都成立，不要求独立。**

1. **为什么成立**
   - **按 $(X, Y)$ 的联合分布展开**：
     $$E[X + Y] = \sum_{x, y} (x + y) P(X = x, Y = y) = \sum_x x \underbrace{\sum_y P(X = x, Y = y)}_{P(X = x)} + \sum_y y \underbrace{\sum_x P(X = x, Y = y)}_{P(Y = y)}.$$
   - **整个推导没用到独立**：只是把和拆开、交换求和次序，内层求和正好是单个变量的分布。
2. **推广到 $n$ 个、带系数**
   - **$E[\sum_i c_i X_i] = \sum_i c_i E[X_i]$**：$c_i$ 是常数。
   - **乘法不行**：$E[XY] = E[X] E[Y]$ 要求独立。
   - **例子**：掷两次骰子，“点数之和”的期望是 $3.5 + 3.5 = 7$；两次点数相同（完全相关）时“点数之和”就是 $2X$，期望还是 7。

### 1.3 指示变量：期望就是概率

**一件事发生取 1、不发生取 0 的变量叫指示变量，它的期望就是这件事的概率。**

1. **指示变量的期望**
   - **定义**：$I_A = [A \text{ 发生}]$，$E[I_A] = 1 \cdot P(A) + 0 \cdot P(\bar A) = P(A)$。
2. **“个数”都能拆成指示变量的和**
   - **个数 = 每个候选对象各贡献一个 0 或 1**：由线性性，期望个数 = 每个对象“被数到”的概率之和。
   - **例子**：随机排列的不动点个数，拆成“第 $i$ 位是不是不动点”，每个概率 $\frac{1}{n}$，期望是 $n \cdot \frac{1}{n} = 1$。不动点个数的分布很复杂，但期望一步出来。
3. **对象地位对称时，只算一个**
   - **随机排列、均匀打乱下，每个对象被数到的概率一样**：期望个数 = 对象个数 × 一个对象被数到的概率。
   - **例子**：上面的不动点，每一位都是 $\frac{1}{n}$，所以只算第 1 位；随机打乱后的同色段数，$m - 1$ 对相邻位置的概率一样，只算一对（3.2）。

### 1.4 全期望：先看第一步，再对后面取平均

**从状态 $u$ 出发的期望 = 对第一步的每种走法，按概率加权“这一步的代价 + 从下一个状态出发的期望”。**

1. **递推式**
   - **模型**：在有向图上从 $u$ 出发，以概率 $P_{u,v}$ 走到 $v$、花费 $w_{u,v}$，走到没有出边的点停下。设 $D_u$ 是从 $u$ 出发到停下的总花费。
   - **式子**：
     $$E[D_u] = \sum_{u \to v} P_{u,v} \bigl(w_{u,v} + E[D_v]\bigr).$$
2. **为什么成立**
   - **按第一步分类**：第一步走到 $v$ 的条件下，$D_u = w_{u,v} + D_v$，而 $D_v$ 的分布和“从 $v$ 重新出发”一样。
   - **展开就是交换求和**：$E[D_u] = \sum_d d \sum_v P_{u,v} P(D_v = d - w_{u,v})$，令 $d' = d - w_{u,v}$、交换两层求和，内层得到 $w_{u,v} + E[D_v]$。
3. **它决定了期望 DP 的方向**
   - **终点的值已知**：停下的点 $E[D] = 0$。
   - **其余点由后继决定**：所以期望 DP 一般从终点往回推（第 5 节）；后继又回到自己时就是有环（第 6 节）。

### 1.5 常见分布的期望

**几何分布的期望 $\frac{1}{p}$ 最常用：每次成功概率 $p$，平均要试 $\frac{1}{p}$ 次。**

| 分布 | 描述 | 期望 | 方差 |
| --- | --- | --- | --- |
| 两点分布 | 一次试验成功取 1，概率 $p$ | $p$ | $p(1 - p)$ |
| 二项分布 $B(n, p)$ | $n$ 次独立试验的成功次数 | $np$ | $np(1 - p)$ |
| 几何分布 | 第一次成功时试了几次 | $\frac{1}{p}$ | $\frac{1 - p}{p^2}$ |
| 离散均匀 | $1 \sim n$ 等概率 | $\frac{n + 1}{2}$ | $\frac{n^2 - 1}{12}$ |

1. **几何分布的期望用 1.4 一步推出**
   - **第一次试**：成功（概率 $p$）就结束；失败（概率 $1 - p$）就回到原状态重来。所以 $E = 1 + (1 - p) E$，解出 $E = \frac{1}{p}$。
   - **方程右边出现了自己**：这就是最简单的“有环”，第 6 节的题都是这样移项解出来的。
   - **例子**：密码有 $N$ 种等概率的可能，每次猜错后密码重新随机，猜中的期望次数是 $N$。
2. **二项分布的期望就是线性性**
   - **$n$ 次试验每次是一个两点分布**：期望各是 $p$，加起来 $np$，不用算组合数。

### 1.6 取模输出：分数换成乘逆元

**题目要“期望模 $p$”时，分数 $\frac{a}{b}$ 写成 $a \cdot b^{-1} \bmod p$，加减乘照常，除法换成乘逆元。**

- **为什么可以**：答案是有理数 $\frac{a}{b}$，模质数 $p$ 下 $b$ 有逆元，$\frac{a}{b}$ 对应唯一的 $a b^{-1}$；整个推导只用了加减乘除，每一步都可以在模 $p$ 下做。
- **比较大小不能取模**：带决策的期望要取 max/min 时，取模后的数没有大小关系，只能用浮点数，或者用分子分母都存的分数类（练习 6）。

## 2. 能解决什么问题

**期望题按“求的是什么”分成六类：第 1、2 类直接拆，不用设状态；第 3 到 5 类设状态写方程；第 6 类局面太多，换成找势能。**

1. **求某种东西个数的期望：拆成指示变量**
   - **信号**：“期望有几个 / 期望多少对 / 期望多少段”。
   - **怎么化**：把个数写成每个候选对象的 0/1 之和，每个对象只算它被数到的概率，再加起来（1.3）。对象太多时，同一类对象的概率一样，按类相乘。
   - **例子：随机打乱后的同色段数**：4 颗水晶 `1 1 2 2` 随机打乱，求期望有几段同色（完整题见 3.2）。
     1. **拆成指示变量**：段数 = 1 + 相邻两颗颜色不同的次数，后者是 3 对相邻位置各贡献一个 0 或 1。
     2. **对称，只算一对**：每对相邻位置异色的概率都一样，等于从 4 颗里按先后抽两颗、颜色不同的概率。一共 $4 \times 3 = 12$ 种抽法，同色的 $2 + 2 = 4$ 种，异色概率 $\frac{8}{12} = \frac23$。
     3. **加起来**：$1 + 3 \times \frac23 = 3$。
2. **求最大值、最小值的期望：先求分布函数**
   - **信号**：“$n$ 次里的最大值 / 最晚完成的时间”。
   - **怎么化**：$P(\max = y)$ 不好求，$P(\max \le y)$ 是“每次都 $\le y$”，独立时直接相乘；作差得到 $P(\max = y)$，或者用尾和公式 $E[Y] = \sum_{y \ge 1} P(Y \ge y)$（第 4 节）。
   - **例子：两面骰子掷两次，最大点数的期望**（完整题见 4.2）。
     1. **先求“不超过”**：$P(\max \le 1) = \left(\frac12\right)^2 = \frac14$，$P(\max \le 2) = 1$。
     2. **作差**：$P(\max = 1) = \frac14$，$P(\max = 2) = 1 - \frac14 = \frac34$。
     3. **加权**：$E = 1 \times \frac14 + 2 \times \frac34 = 1.75$。直接数也一样：四种结果 (1,1)、(1,2)、(2,1)、(2,2) 的最大值是 1、2、2、2。
3. **求“直到某事发生”的期望步数：几何分布或期望 DP**
   - **信号**：“期望多少次操作后停止”，每一步只依赖当前状态。
   - **怎么化**：成功率不变时就是几何分布 $\frac{1}{p}$；成功率随状态变时设 $E[s]$ 为从状态 $s$ 到停止还要的期望步数，由 1.4 从终点往回推（第 5 节）。
   - **例子：成功率不变，掷骰子直到出 6**：每次成功率 $\frac16$，是几何分布，期望 6 次。
   - **例子：成功率随状态变，袋子里的硬币**：金、银、铜币 98、99、99 枚，每次摸一枚放回，再加一枚同种的，某种到 100 枚就停，求期望摸几次（完整题见 5.2）。
     1. **设状态**：$E[a][b][c]$ 为从 $(a, b, c)$ 到停止还要摸的期望次数，有一种到 100 时为 0。
     2. **看第一步**：一共 296 枚。摸到银或铜（概率 $\frac{198}{296}$）就到 100，停；摸到金（概率 $\frac{98}{296}$）变成 $(99, 99, 99)$，那里再摸一次必停，$E[99][99][99] = 1$。
     3. **代进去**：$E[98][99][99] = 1 + \frac{98}{296} \times 1 \approx 1.331$。
4. **带决策的期望：DP 里取最优**
   - **信号**：“选一种策略使期望最小 / 最大”。
   - **怎么化**：每个状态在几种决策的期望里取最优；只改一处时，用“到达这个点的概率 × 这个点期望的变化量”算整体的变化（5.4）。
   - **例子：删一条通道，让期望步数最小**：4 个房间，每对 $i < j$ 都有一条 $i \to j$ 的通道。从 1 出发，每到一个房间就等概率选一条出边走，到 4 停。出发前可以删一条通道，求期望走几步的最小值（完整题见 5.4）。
     1. **不删时倒着推**：$E_4 = 0$，$E_3 = 1$，$E_2 = 1 + \frac{1 + 0}{2} = 1.5$，$E_1 = 1 + \frac{1.5 + 1 + 0}{3} \approx 1.833$。
     2. **在房间 $u$ 删边只改变 $E_u$，删期望最大的那个后继**：在 1 删去通向 2 的，$E_1' = 1 + \frac{1 + 0}{2} = 1.5$；在 2 删去通向 3 的，$E_2' = 1 + 0 = 1$；3 只有一条出边，不能删。
     3. **整体变化 = 到达 $u$ 的概率 × $E_u$ 的变化**：到达 1 的概率是 1，答案变成 $1.5$；到达 2 的概率是 $\frac13$，答案变成 $1.833 + \frac13 \times (1 - 1.5) \approx 1.667$。取最小，答案 1.5。
5. **状态之间有环：列方程组**
   - **信号**：失败会退回之前的状态，随机游走可以来回走。
   - **怎么化**：每个状态一个方程，结构简单时手消（6.2 退回存档点），一般情况用高斯消元（[L2 3.3](/zh/algo/l2-gaussian-elimination/) 图上随机游走）。
   - **例子：失败退回存档点**：每次尝试一关，$\frac12$ 概率过关，失败就回到第 1 关重打（只有第 1 关有存档点），求打通 2 关的期望尝试次数（完整题见 6.2）。
     1. **打通 1 关**：成功率不变，几何分布，$E_1 = 2$。
     2. **打通 2 关**：先花 $E_1$ 次过第 1 关，再试第 2 关一次；失败（概率 $\frac12$）从头再来，还要 $E_2$ 次。方程右边又出现了 $E_2$：$E_2 = E_1 + 1 + \frac12 E_2$。
     3. **移项**：$E_2 = 2(E_1 + 1) = 6$。同样推下去，一段 $L$ 关是 $2^{L+1} - 2$。
6. **所有对象一起随机变化：找势能**
   - **信号**：每一轮所有集合 / 所有元素同时变化，局面的种类多到没法当状态。
   - **怎么化**：给每个对象定一个分数，让整个局面的分数每轮期望恰好加 1，期望轮数 = 终局分数 − 开局分数（第 7 节）。
   - **例子：随机配对、搬元素，直到合成一个集合**：两个集合各有 1 个元素。每轮把这 2 个元素配成一对，随机选其中一个，搬进对方的集合。求合成一个集合的期望轮数（完整题见 7.2）。
     1. **按集合大小给势能**：设大小为 $s$ 的集合势能 $f(s)$，要求它每轮的期望势能恰好增加 $\frac{s}{N}$（这里 $N = 2$）。所有集合大小加起来是 $N$，整个局面每轮就恰好加 1。空集合消失，$f(0) = 0$；再取 $f(1) = 0$。
     2. **列大小为 1 的方程**：这个元素一定配到外面，$\frac12$ 概率它搬出去（大小变 0），$\frac12$ 概率对方搬进来（大小变 2）：$\frac12 f(0) + \frac12 f(2) - f(1) = \frac12$，得 $f(2) = 1$。
     3. **期望轮数 = 终局势能 − 开局势能**：$f(2) - 2 f(1) = 1$。确实一轮之后必定合成一个。

求的是概率本身时，做法和第 3 类一样设状态递推，只是存的是概率不是期望。
   - **例子：从 0 出发，每步等概率走 1 格或 2 格，求踩到第 3 格的概率**。
     1. **设状态**：$f[i]$ 为从 $i$ 出发踩到 3 的概率。$f[3] = 1$；走到 4 说明跳过了 3，$f[4] = 0$。
     2. **转移是后继的平均**：$f[i] = \frac12 f[i + 1] + \frac12 f[i + 2]$，倒着算：$f[2] = \frac12$，$f[1] = \frac12 \times \frac12 + \frac12 \times 1 = \frac34$，$f[0] = \frac12 \times \frac34 + \frac12 \times \frac12 = \frac58$。
     3. **直接数验证**：踩到 3 的走法是 1+1+1、1+2、2+1，概率 $\frac18 + \frac14 + \frac14 = \frac58$。

## 3. 线性性：拆成指示变量

### 3.1 例：CF 1612E Messages，按条消息算贡献

[CF 1612E](https://codeforces.com/problemset/problem/1612/E)

1. **题面**

   $n$ 个学生，学生 $i$ 需要读到第 $m_i$ 条消息，他最多读 $k_i$ 条。你置顶 $t$ 条消息：若 $t \le k_i$，学生 $i$ 读完全部置顶；否则他从置顶里等概率选 $k_i$ 条读。选择置顶哪些消息，使“读到自己那条消息的学生数”的期望最大。

   - **输入**：第一行 $n$（$1 \le n \le 2 \cdot 10^5$），接下来 $n$ 行 $m_i, k_i$（$1 \le m_i \le 2 \cdot 10^5$，$1 \le k_i \le 20$）。
   - **输出**：第一行 $t$，第二行 $t$ 个不同的消息编号。多解输出任意一个。

   **样例 1 输入**

   ```text
   3
   10 1
   10 2
   5 2
   ```

   **样例 1 输出**

   ```text
   2
   5 10
   ```

   **样例 2 输入**

   ```text
   3
   10 1
   5 2
   10 1
   ```

   **样例 2 输出**

   ```text
   1
   10
   ```

   **样例 3 输入**

   ```text
   4
   1 1
   2 2
   3 3
   4 4
   ```

   **样例 3 输出**

   ```text
   3
   2 3 4
   ```

   **样例 4 输入**

   ```text
   3
   13 2
   42 2
   37 2
   ```

   **样例 4 输出**

   ```text
   3
   42 13 37
   ```

2. **思路**
   1. **按学生拆成指示变量**：读到的学生数 = $\sum_i [\text{学生 } i \text{ 读到 } m_i]$。$m_i$ 没置顶时概率是 0；置顶了时，他读的 $\min(k_i, t)$ 条是 $t$ 条里等概率的子集，读到某一条的概率是 $\frac{\min(k_i, t)}{t}$。
   2. **固定 $t$ 后按消息合并**：置顶消息 $x$ 贡献 $\frac{1}{t} \sum_{m_i = x} \min(k_i, t)$，各条消息的贡献互不影响，所以选贡献最大的 $t$ 条。
   3. **$t > 20$ 时分子和 $t$ 无关**：$k_i \le 20$，$\min(k_i, t) = k_i$，每条消息的分数固定是 $w_x = \sum_{m_i = x} k_i$。按 $w$ 排一次序，前缀和就给出每个 $t$ 的最优值。$t \le 20$ 时每个 $t$ 单独算一遍分数。
   4. **比较 $\frac{S_t}{t}$ 用交叉相乘**：$S_t \cdot t' > S_{t'} \cdot t$，不用浮点。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;
   typedef long long ll;

   int main() {
       ios::sync_with_stdio(false);
       cin.tie(nullptr);
       int n;
       cin >> n;
       vector<int> m(n), k(n);
       for (int i = 0; i < n; i++) cin >> m[i] >> k[i];
       vector<int> ids(m);                                  // 出现过的消息
       sort(ids.begin(), ids.end());
       ids.erase(unique(ids.begin(), ids.end()), ids.end());
       int D = ids.size();
       vector<ll> sc(200001);
       ll bestS = -1;                                       // 最优的期望是 bestS / bestT
       int bestT = 1;
       vector<int> pick;
       auto better = [&](ll S, int t) { return bestS < 0 || S * bestT > bestS * t; };

       // t <= 20：消息 x 的分数是 sum min(k_i, t)，取前 t 大
       for (int t = 1; t <= min(20, D); t++) {
           for (int x : ids) sc[x] = 0;
           for (int i = 0; i < n; i++) sc[m[i]] += min(k[i], t);
           vector<int> ord = ids;
           partial_sort(ord.begin(), ord.begin() + t, ord.end(), [&](int x, int y) { return sc[x] > sc[y]; });
           ll S = 0;
           for (int j = 0; j < t; j++) S += sc[ord[j]];
           if (better(S, t)) bestS = S, bestT = t, pick.assign(ord.begin(), ord.begin() + t);
       }
       // t > 20：分数固定是 w_x = sum k_i，排一次序，前缀和给出每个 t
       if (D > 20) {
           for (int x : ids) sc[x] = 0;
           for (int i = 0; i < n; i++) sc[m[i]] += k[i];
           vector<int> ord = ids;
           sort(ord.begin(), ord.end(), [&](int x, int y) { return sc[x] > sc[y]; });
           ll S = 0;
           int bigT = 0;
           for (int t = 1; t <= D; t++) {
               S += sc[ord[t - 1]];
               if (t > 20 && better(S, t)) bestS = S, bestT = t, bigT = t;
           }
           if (bigT) pick.assign(ord.begin(), ord.begin() + bigT);
       }
       cout << bestT << '\n';
       for (int j = 0; j < bestT; j++) cout << pick[j] << " \n"[j + 1 == bestT];
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O(20 (n + D \log D))$，$D$ 是出现过的消息数。$t \le 20$ 的每一轮扫一遍学生、部分排序一次。
   - **不用置顶没人要的消息**：每条消息的贡献 $\frac{\min(k_i, t)}{t}$ 随 $t$ 增大不升，多置顶一条 0 分消息不会更好，所以 $t$ 只枚举到 $D$。
   - **分母不同的期望不能直接比**：$S_t$ 是整数，比较 $\frac{S_t}{t}$ 交叉相乘，最大 $4 \cdot 10^6 \times 2 \cdot 10^5$，`long long` 够用。

### 3.2 例：2026 吉林省赛 M 水晶城堡，随机打乱后的色段数

[Gym 106567M](https://codeforces.com/gym/106567/problem/M)

1. **题面**

   一排 $n$ 颗水晶，第 $i$ 颗颜色是 $a_i$。$q$ 次询问 $[l, r]$：把这段取下来随机打乱（所有不同的颜色序列等概率），求极大同色连续段个数的期望，模 998244353。

   - **输入**：第一行 $T$；每组第一行 $n, q$，第二行 $a_1, \dots, a_n$（$1 \le a_i \le n$），再 $q$ 行 $l, r$。$n$、$q$ 的总和都 $\le 10^5$。
   - **输出**：每个询问一行。

   **样例 1 输入**

   ```text {hl_lines=["2-5"]}
   1
   4 2
   1 1 2 2
   1 2
   1 4
   ```

   **样例 1 输出**

   ```text {hl_lines=["1-2"]}
   1
   3
   ```

   **样例 2 输入**

   ```text {hl_lines=["2-8"]}
   1
   10 5
   3 5 3 3 6 4 8 2 3 5
   6 9
   1 8
   8 10
   4 9
   7 7
   ```

   **样例 2 输出**

   ```text {hl_lines=["1-5"]}
   4
   748683272
   3
   665496241
   1
   ```

2. **思路**
   记这次询问的段长 $m = r - l + 1$，颜色 $c$ 在这段里出现 $\mathit{cnt}_c$ 次。
   1. **段数 = 1 + 相邻两颗颜色不同的次数**：从左往右，每遇到一颗和前一颗颜色不同，就多出一段。
   2. **线性性加对称性，只算一对**：相邻异色的次数是 $m - 1$ 个指示变量之和，由线性性，它的期望是每对相邻位置异色的概率之和（1.3）。打乱是对称的，这 $m - 1$ 个概率都一样，所以期望段数 $= 1 + (m - 1) \times$ 一对相邻颜色不同的概率。
   3. **这个概率就是从段里随便抽两颗、颜色不同的概率**：按先后抽两颗有 $m(m - 1)$ 种，同色的有 $S = \sum_c \mathit{cnt}_c (\mathit{cnt}_c - 1)$ 种。代进去化简：
      $$E[\text{段数}] = 1 + (m - 1)\Bigl(1 - \frac{S}{m(m - 1)}\Bigr) = m - \frac{S}{m}.$$
      样例 1 的询问 $[1, 4]$（`1 1 2 2`）：$m = 4$，$S = 2 + 2 = 4$，答案 $4 - 1 = 3$。
   4. **每次询问只差一个 $S$，用莫队维护**：加进一颗颜色 $c$，它和原来每颗 $c$ 能按先后配成两种同色对，$S$ 加 $2 \mathit{cnt}_c$，再把 $\mathit{cnt}_c$ 加 1；删掉一颗就先减 $\mathit{cnt}_c$，再让 $S$ 减 $2 \mathit{cnt}_c$。

   > 期望段数的本质：线性性把段数拆成每对相邻异色的概率之和，对称性让这些概率都等于随便抽两颗异色的概率。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;
   typedef long long ll;
   const ll MOD = 998244353;

   ll pw(ll b, ll e) {
       ll r = 1;
       for (b %= MOD; e; e >>= 1, b = b * b % MOD)
           if (e & 1) r = r * b % MOD;
       return r;
   }

   int main() {
       ios::sync_with_stdio(false);
       cin.tie(nullptr);
       int T;
       cin >> T;
       while (T--) {
           int n, q;
           cin >> n >> q;
           vector<int> a(n + 1);
           for (int i = 1; i <= n; i++) cin >> a[i];
           vector<int> L(q), R(q), ord(q);
           for (int i = 0; i < q; i++) cin >> L[i] >> R[i];
           int B = max(1, (int)(n / sqrt((double)q)));
           iota(ord.begin(), ord.end(), 0);
           sort(ord.begin(), ord.end(), [&](int x, int y) {
               if (L[x] / B != L[y] / B) return L[x] / B < L[y] / B;
               return (L[x] / B) & 1 ? R[x] > R[y] : R[x] < R[y];
           });
           vector<ll> cnt(n + 1, 0);
           ll S = 0;                                     // S = sum_c cnt_c (cnt_c - 1)
           auto ins = [&](int i) { S += 2 * cnt[a[i]]; cnt[a[i]]++; };
           auto del = [&](int i) { cnt[a[i]]--; S -= 2 * cnt[a[i]]; };
           vector<ll> ans(q);
           int cl = 1, cr = 0;
           for (int id : ord) {
               while (cr < R[id]) ins(++cr);
               while (cl > L[id]) ins(--cl);
               while (cr > R[id]) del(cr--);
               while (cl < L[id]) del(cl++);
               ll m = R[id] - L[id] + 1;
               // E = m - S / m
               ans[id] = ((m - S % MOD * pw(m, MOD - 2)) % MOD + MOD) % MOD;
           }
           for (int i = 0; i < q; i++) cout << ans[i] << '\n';
       }
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O((n + q)\sqrt{n})$，莫队移动端点每次 $O(1)$。
   - **“所有不同的颜色序列等概率”**：同色水晶不区分，但和“每颗看成不同、均匀打乱”得到的颜色序列分布一样，所以可以按每颗不同算概率。
   - **$m = 1$ 不用特判**：$S = 0$，答案 1。

> **看到“随机排列后某种计数的期望”时**
>
> - **拆成相邻位置的指示变量**：期望的线性性把整体期望化成单个位置的概率。
> - **排列对称，所有位置概率一样**：只算一个位置的概率，再乘位置数。

## 4. 分布函数：最大值的期望

### 4.1 $P(Y \le y)$ 好求，作差得到 $P(Y = y)$

**最大值“等于 $y$”要求有一次恰好是 $y$、其余都不超过，不好数；“不超过 $y$”只要每次都不超过，独立时直接相乘。**

1. **作差**
   - **$P(Y = y) = P(Y \le y) - P(Y \le y - 1)$**：$P(Y \le y)$ 叫分布函数。
   - **最大值的分布函数**：$n$ 次独立、每次 $\le y$ 的概率都是 $F(y)$，则 $P(\max \le y) = F(y)^n$。最小值反过来用 $P(\min \ge y) = (1 - F(y - 1))^n$。
2. **尾和公式：不作差也行**
   - **取值是非负整数时 $E[Y] = \sum_{y \ge 1} P(Y \ge y)$**：$Y = \sum_{y \ge 1} [Y \ge y]$，每个指示变量的期望是 $P(Y \ge y)$，这还是线性性。

#### 复杂度

$O(m \log n)$：取值有 $m$ 种，每种算一次 $F(y)^n$（快速幂 $O(\log n)$）。

### 4.2 例：CF 453A Little Pony and Expected Maximum

[CF 453A](https://codeforces.com/problemset/problem/453/A)

1. **题面**

   一枚 $m$ 面骰子，第 $i$ 面点数是 $i$，每面概率 $\frac{1}{m}$。独立掷 $n$ 次，求最大点数的期望，误差不超过 $10^{-4}$。

   - **输入**：一行 $m, n$（$1 \le m, n \le 10^5$）。
   - **输出**：一个实数。

   **样例 1 输入**

   ```text
   6 1
   ```

   **样例 1 输出**

   ```text
   3.500000000000
   ```

   **样例 2 输入**

   ```text
   6 3
   ```

   **样例 2 输出**

   ```text
   4.958333333333
   ```

   **样例 3 输入**

   ```text
   2 2
   ```

   **样例 3 输出**

   ```text
   1.750000000000
   ```

2. **思路**
   1. **每次都 $\le y$ 的概率**：$P(Y \le y) = \left(\frac{y}{m}\right)^n$。
   2. **作差求期望**：
      $$E[Y] = \sum_{y = 1}^{m} y \left[\left(\frac{y}{m}\right)^n - \left(\frac{y - 1}{m}\right)^n\right].$$
      样例 3（$m = 2$，$n = 2$）：$1 \times \frac14 + 2 \times \left(1 - \frac14\right) = 1.75$。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;

   int main() {
       int m, n;
       cin >> m >> n;
       double ans = 0;
       for (int y = 1; y <= m; y++)
           ans += y * (pow((double)y / m, n) - pow((double)(y - 1) / m, n));
       printf("%.12f\n", ans);
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O(m \log n)$，`pow` 内部是对数级。
   - **不要先算 $y^n$ 再除 $m^n$**：$10^5$ 的 $10^5$ 次方远超 `double` 范围，要先除再乘方，$\frac{y}{m} \le 1$ 不会溢出。

## 5. 期望 DP：从终点往回推

### 5.1 设“从这里到结束还要多少”，终点是 0

**设 $E[s]$ 为从状态 $s$ 出发到结束的期望，结束状态是 0，其余状态按 1.4 由后继推出；状态图无环时按拓扑序倒着算。**

1. **为什么设“到结束还要多少”**
   - **终点的值已知**：结束了就不再花费，$E = 0$。
   - **起点的值未知**：从起点往后推时，每个状态的到达概率还要另算；倒着推只需要后继的期望。
2. **转移就是 1.4**
   - **$E[s] = \sum_{s \to s'} P(s \to s') \bigl(\text{这一步的代价} + E[s']\bigr)$**：每一步代价是 1 时就是“期望步数”。
3. **转移回到自己时先移项**
   - **自环**：$E[s] = p \cdot E[s] + (\text{其他项})$，移项得 $E[s] = \frac{\text{其他项}}{1 - p}$。几何分布（1.5）就是这样。5.3 是一个必须单独处理的自环。

#### 复杂度

$O(\text{状态数} \times \text{每个状态的转移数})$，和普通 DP 一样。

   - **输出**：一个实数。

   **样例 1 输入**

   ```text
   99 99 99
   ```

   **样例 1 输出**

   ```text
   1.000000000
   ```

   **样例 2 输入**

   ```text
   98 99 99
   ```

   **样例 2 输出**

   ```text
   1.331081081
   ```

   ```text

   ```

2. **思路**

   ```cpp
       cin >> A >> B >> C;
       for (int a = 99; a >= 0; a--)
           for (int b = 99; b >= 0; b--)
               for (int c = 99; c >= 0; c--) {
                   int s = a + b + c;
                   if (s == 0) continue;                 // 袋子空的状态到不了

               }
       printf("%.9f\n", E[A][B][C]);
   }
   ```

### 5.3 例：CF 908D New Year and Arbitrary Arrangement，自环要先移项

[CF 908D](https://codeforces.com/problemset/problem/908/D)

1. **题面**

   给定 $k, p_a, p_b$。从空序列开始，每秒以 $\frac{p_a}{p_a + p_b}$ 的概率在末尾加一个 `a`，否则加一个 `b`。当序列里子序列 `ab` 的个数至少为 $k$ 时停止。求停止时 `ab` 子序列个数的期望，模 $10^9 + 7$。

   - **输入**：一行 $k, p_a, p_b$（$1 \le k \le 1000$，$1 \le p_a, p_b \le 10^6$）。
   - **输出**：一个整数。

   **样例 1 输入**

   ```text
   1 1 1
   ```

   **样例 1 输出**

   ```text
   2
   ```

   **样例 2 输入**

   ```text
   3 1 4
   ```

   **样例 2 输出**

   ```text
   370000006
   ```

2. **思路**
   记 $q_a = \frac{p_a}{p_a + p_b}$，$q_b = 1 - q_a$。
   1. **状态只要两个数**：当前已有 $i$ 个 `ab`、$j$ 个 `a`。加 `a` 变成 $(i, j + 1)$；加 `b` 时前面每个 `a` 都和它配成一个 `ab`，变成 $(i + j, j)$。设 $f(i, j)$ 为从这里出发、停止时 `ab` 个数的期望：
      $$f(i, j) = q_a f(i, j + 1) + q_b f(i + j, j), \qquad i < k.$$
   2. **$i + j \ge k$ 时有闭式**：下一个 `b` 一来就停，停时有 $i + j + (\text{这之前又加的 a 的个数})$ 个 `ab`。“第一个 `b` 之前加几个 `a`”的期望是 $\frac{q_a}{q_b} = \frac{p_a}{p_b}$（几何分布的期望减 1），所以 $f(i, j) = i + j + \frac{p_a}{p_b}$。这一步把 $j$ 无上限的状态截在了 $k$。
   3. **$j = 0$ 是自环**：没有 `a` 时加 `b` 不产生 `ab`，$(i, 0)$ 回到自己：$f(i, 0) = q_a f(i, 1) + q_b f(i, 0)$，移项得 $f(i, 0) = f(i, 1)$。答案 $f(0, 0) = f(0, 1)$。
   4. **计算顺序**：$f(i, j)$ 依赖 $j$ 更大的和 $i$ 更大的，$i$ 从 $k - 1$ 往下、$j$ 从大往小算。

   样例 1（$k = 1$）：$f(0, 0) = f(0, 1) = 0 + 1 + \frac{1}{1} = 2$。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;
   typedef long long ll;
   const ll MOD = 1e9 + 7;

   ll pw(ll b, ll e) {
       ll r = 1;
       for (b %= MOD; e; e >>= 1, b = b * b % MOD)
           if (e & 1) r = r * b % MOD;
       return r;
   }

   int main() {
       ll k, pa, pb;
       cin >> k >> pa >> pb;
       ll qa = pa * pw(pa + pb, MOD - 2) % MOD, qb = pb * pw(pa + pb, MOD - 2) % MOD;
       ll ab = pa * pw(pb, MOD - 2) % MOD;                  // 第一个 b 之前 a 个数的期望 pa / pb
       vector<vector<ll>> dp(k, vector<ll>(k + 1, 0));
       // i + j >= k：f = i + j + pa / pb
       auto f = [&](ll i, ll j) { return i + j >= k ? (i + j + ab) % MOD : dp[i][j]; };
       for (ll i = k - 1; i >= 0; i--)
           for (ll j = k - 1 - i; j >= 1; j--)
               dp[i][j] = (qa * f(i, j + 1) + qb * f(i + j, j)) % MOD;
       cout << f(0, 1) << '\n';                             // f(0, 0) = f(0, 1)
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O(k^2)$。
   - **不截断状态就无限**：$j$ 可以一直加 `a` 无限增大，靠第 2 步的闭式在 $i + j \ge k$ 处截住。
   - **自环不能直接套转移**：$j = 0$ 时 $f(i + j, j)$ 就是 $f(i, 0)$ 自己，按循环顺序它还没算出来；先移项成 $f(i, 0) = f(i, 1)$。

### 5.4 例：ABC 144F Fork in the Road，删一条边只改一个点

   - **输出**：一个实数。

   ```text

   1 4

   1 3
   1 2

   2 4
   ```

   **样例 1 输出**

   ```text
   1.5000000000
   ```

   **样例 2 输入**


2. **思路**
   1. **不删边时倒着推**：$E_N = 0$，$E_u = 1 + \frac{1}{\deg u} \sum_{u \to v} E_v$，$u$ 从 $N - 1$ 到 1。
   2. **删 $u$ 的一条出边只改变 $E_u$**：边都是小编号指向大编号，$u$ 后面的房间不会再回到 $u$，它们的期望不变。$u$ 至少要剩一条出边，所以只能在 $\deg u \ge 2$ 的点删；删掉期望最大的那个后继 $v_0$ 最好：
      $$E_u' = 1 + \frac{1}{\deg u - 1}\Bigl(\sum_{u \to v} E_v - E_{v_0}\Bigr).$$
   3. **$E_1$ 的变化 = 到达 $u$ 的概率 × $E_u$ 的变化**：从 1 出发，到达 $u$ 之前的过程不经过 $u$ 的出边，不受影响；到达 $u$（概率 $P_u$）之后的期望从 $E_u$ 变成 $E_u'$。所以新的答案是 $E_1 + P_u (E_u' - E_u)$。$P_u$ 正着推：$P_1 = 1$，$P_v \mathrel{+}= \frac{P_u}{\deg u}$。
   4. **对每个 $u$ 算一遍，取最小**：再和不删比较。

   样例 1：不删时 $E_3 = 1$、$E_2 = 1.5$、$E_1 = 1 + \frac{1.5 + 1 + 0}{3} \approx 1.83$；在 1 删去通向 2 的边，$E_1' = 1 + \frac{1 + 0}{2} = 1.5$。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;

   int main() {
       int N, M;
       cin >> N >> M;
       vector<vector<int>> g(N + 1);
       for (int i = 0; i < M; i++) {
           int s, t;
           cin >> s >> t;
           g[s].push_back(t);
       }
       vector<double> E(N + 1, 0), P(N + 1, 0);
       for (int u = N - 1; u >= 1; u--) {                   // 倒着推期望
           for (int v : g[u]) E[u] += E[v];
           E[u] = 1 + E[u] / g[u].size();
       }
       P[1] = 1;                                            // 正着推到达概率
       for (int u = 1; u < N; u++)
           for (int v : g[u]) P[v] += P[u] / g[u].size();
       double ans = E[1];
       for (int u = 1; u < N; u++) {
           int d = g[u].size();
           if (d < 2) continue;
           double sum = 0, mx = 0;
           for (int v : g[u]) sum += E[v], mx = max(mx, E[v]);
           // 删掉期望最大的后继：E_u' = 1 + (sum - mx) / (d - 1)，答案变化 P_u (E_u' - E_u)
           ans = min(ans, E[1] + P[u] * (1 + (sum - mx) / (d - 1) - E[u]));
       }
       printf("%.10f\n", ans);
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O(N + M)$。对每条边删一次、整张图重算是 $O(M^2)$，对每个点重算是 $O(NM)$，都比这个慢。
   - **删边后其余点的期望不变，是因为图按编号无环**：有环的图删一条边会影响能回到它的所有点，不能这样只改一个点。
   - **出度为 1 的点不能删**：删了就走不出去。

> **看到“期望 DP 里改一处，求最优”时**
>
> - **先问改动影响哪些状态**：无环图里改 $u$ 的出边，只有 $u$ 和它前面的状态变。
> - **整体变化 = 到达概率 × 局部变化**：正着推一遍到达概率，每个候选改动 $O(1)$ 算出答案。

## 6. 状态有环：列方程

### 6.1 能手消就手消，不能就高斯消元

**状态会回到之前的状态时，期望之间互相依赖，排不出计算顺序，就把每个状态的方程都列出来一起解。**

1. **结构简单时手消**
   - **只退回到少数几个固定状态**：比如失败就回到最近的存档点。把方程按顺序代入，每个期望都写成“存档点的期望 + 常数”，最后存档点的方程里只剩它自己，移项解出。
2. **一般情况用高斯消元**
   - **$n$ 个状态、$n$ 个方程**：$E_u - \sum_v P_{u,v} E_v = c_u$，终点 $E = 0$。实数下 $O(n^3)$，$n$ 到几百。
   - **例子**：图上随机游走，见 [L2 3.3 洛谷 P3232 游走](/zh/algo/l2-gaussian-elimination/)；模质数的写法见 L2 第 4 节。

### 6.2 例：CF 1453D Checkpoints，退回存档点的期望是 $2^{L+1} - 2$

[CF 1453D](https://codeforces.com/problemset/problem/1453/D)

1. **题面**

   游戏有 $n$ 关，玩家从第 1 关依次往后打。每关可以有存档点，第 1 关一定有。每次尝试一关，有 $\frac12$ 概率过关、进入下一关；失败就回到最近一个经过的存档点重打。构造不超过 2000 关、指定哪些关有存档点，使通关的期望尝试次数恰好是 $k$；做不到输出 $-1$。

   - **输入**：第一行 $t$（$1 \le t \le 50$），每组一行 $k$（$1 \le k \le 10^{18}$）。
   - **输出**：每组输出 $-1$，或者两行：关数 $n$，以及 $n$ 个 0/1 表示每关有没有存档点（第一个必须是 1）。多解输出任意一个。

   **样例 1 输入**

   ```text {hl_lines=[2,4]}
   4
   1
   2
   8
   12
   ```

   **样例 1 输出**

   ```text {hl_lines=[1,"4-5"]}
   -1
   1
   1
   4
   1 1 1 1
   5
   1 1 0 1 1
   ```

2. **思路**
   1. **存档点把关卡切成互不影响的段**：过了下一个存档点就不会再回到这一段，总期望 = 各段期望之和。
   2. **一段 $L$ 关（只有开头有存档点）的期望 $E_L = 2^{L+1} - 2$**：要过前 $L$ 关，先过前 $L - 1$ 关（期望 $E_{L-1}$ 次），再试第 $L$ 关一次：成功就结束，失败（概率 $\frac12$）从头再来。方程右边又出现 $E_L$：
      $$E_L = E_{L-1} + 1 + \tfrac12 E_L \implies E_L = 2 E_{L-1} + 2.$$
      $E_1 = 2$，所以 $E_L = 2^{L+1} - 2$：2、6、14、30……
   3. **每段都是偶数，$k$ 是奇数就无解**：$k$ 为偶数时从大到小贪心，每次取 $2^{L+1} - 2 \le k$ 的最大 $L$。
   4. **长度够用**：取了 $L$ 之后剩下的 $< 2^{L+1}$，下一段的 $L$ 不会更大，而且最多和 $L$ 相等一次。$k \le 10^{18}$ 时 $L \le 58$，总关数不超过 $58 + 57 + \cdots + 1 + 58 < 2000$。

   样例 $k = 8$：取 $L = 2$（6），剩 2 取 $L = 1$，输出 `1 0 1`，和样例的 `1 1 1 1` 不同，但都对。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;
   typedef long long ll;

   int main() {
       int t;
       cin >> t;
       while (t--) {
           ll k;
           cin >> k;
           if (k & 1) {
               cout << -1 << '\n';
               continue;
           }
           vector<int> st;
           while (k > 0) {
               int L = 1;                                   // 最大的 L 使 2^(L+1) - 2 <= k
               while ((1LL << (L + 2)) - 2 <= k) L++;
               k -= (1LL << (L + 1)) - 2;
               st.push_back(1);
               for (int i = 1; i < L; i++) st.push_back(0);
           }
           cout << st.size() << '\n';
           for (size_t i = 0; i < st.size(); i++) cout << st[i] << " \n"[i + 1 == st.size()];
       }
   }
   ```

3. **复杂度和坑**
   - **复杂度**：每组 $O(\log^2 k)$。
   - **$k = 1$ 无解**：最短一段的期望是 2。
   - **不要从小往大拼**：全用 $L = 1$ 需要 $k / 2$ 关，$k$ 到 $10^{18}$ 远超 2000。

## 7. 势能：每轮期望恰好加 1

### 7.1 设一个势能，让期望轮数等于势能的差

**局面太多没法当状态时，给每个对象定一个分数 $f$，让整个局面的分数 $\Phi$ 每轮期望恰好加 1，那么期望轮数 = 终局的 $\Phi$ − 开局的 $\Phi$。**

1. **为什么成立**
   - **$\Phi$ 每轮平均涨 1**：从开局到结束，$\Phi$ 平均涨了多少，就平均过了多少轮。终局只有一种（比如“只剩一个集合”），终局的 $\Phi$ 是常数，所以 $E[\text{轮数}] = \Phi_{\text{终}} - \Phi_{\text{始}}$。这在概率论里叫鞅的可选停时定理。
2. **把“加 1”拆到每个对象头上**
   - **$\Phi$ 是各对象分数之和**：由线性性，$E[\text{新的 } \Phi]$ 是每个对象各自新分数的期望之和。
   - **每个对象的变化只依赖它自己时，方程只剩一维**：让大小为 $s$ 的对象分到 $\frac{s}{N}$（$N$ 是总大小），所有对象加起来正好是 1。于是只要对每个 $s$ 满足 $E[f(s')] - f(s) = \frac{s}{N}$，未知数只有 $f(1), \dots, f(N)$。
3. **解方程**
   - **$N$ 个未知数，$N - 1$ 个方程**：解出 $f$ 后答案是 $f(N) - \sum f(\text{开局各对象大小})$。少的一个方程是自由度，补一个 $f(1) = 0$；方程组没有好的结构时用高斯消元。

#### 复杂度

$O(N^3)$：列方程 $O(N^3)$（常数很小），高斯消元 $O(N^3)$，$N$ 是对象总大小。

### 7.2 例：2025 CCPC 哈尔滨 H How Many Rounds Are Expected?

第 11 届 CCPC 哈尔滨站 H 题，赛时 278 队里 9 队过。

1. **题面**

   有 $n$ 个集合，第 $i$ 个有 $a_i$ 个元素，元素共 $2m$ 个、互不相同（$\sum a_i = 2m$）。每一轮把 $2m$ 个元素随机两两配成 $m$ 对（所有配法等概率）；每一对里随机选一个元素，把它放进和它配对的那个元素所在的集合。求所有元素都落进同一个集合时，期望进行了多少轮，模 998244353。

   - **输入**：第一行 $t$（$1 \le t \le 100$）。每组第一行 $n, m$（$1 \le n \le 2m \le 400$），第二行 $a_1, \dots, a_n$（$\sum a_i = 2m$）。所有数据的 $n$ 之和 $\le 800$，$m$ 之和 $\le 400$。
   - **输出**：每组一行。

   **样例 1 输入**

   ```text {hl_lines=["2-3","6-7"]}
   4
   2 1
   1 1
   2 2
   2 2
   2 2
   1 3
   3 2
   1 1 2
   ```

   **样例 1 输出**

   ```text {hl_lines=[1,3]}
   1
   3
   499122179
   499122180
   ```

   **样例 2 输入**

   ```text {hl_lines=["2-3","6-7"]}
   3
   6 5
   2 1 1 3 1 2
   10 100
   90 12 18 1 1 24 7 4 37 6
   10 200
   102 19 25 11 43 97 19 28 11 45
   ```

   **样例 2 输出**

   ```text {hl_lines=[1,3]}
   347465837
   225202828
   437065763
   ```

2. **思路**
   记 $N = 2m$。
   1. **一个集合的新大小只取决于它自己的大小**：集合大小为 $s$，它的元素配到集合内，这对怎么搬都还在集合里；配到集合外，这对一半概率自己的元素出去（$-1$）、一半概率外面的进来（$+1$）。“有几个元素配到集合外”的分布只和 $s$、$N$ 有关。
   2. **套 7.1**：方程是 $E[f(s')] - f(s) = \frac{s}{N}$（$s = 1, \dots, N - 1$），集合搬空就消失，$f(0) = 0$；答案 $f(N) - \sum f(a_i)$。
   3. **算 $s'$ 的分布**：设 $k$ 个元素配到集合外（$s - k$ 为偶数）。从里外各挑 $k$ 个一一配对有 $\binom{s}{k}\binom{N - s}{k} k!$ 种，剩下的里外各自内部配对。记 $p(x)$ 为 $x$ 个点的完美匹配数（$p(x) = (x - 1)(x - 3) \cdots 1$，$p(0) = 1$）：
      $$P(k) = \frac{\binom{s}{k}\binom{N - s}{k}\, k!\; p(s - k)\; p(N - s - k)}{p(N)}.$$
      这 $k$ 对里有 $j$ 对是外面的进来时 $s' = s - k + 2j$，概率 $\frac{\binom{k}{j}}{2^k}$。
   4. **补 $f(1) = 0$**：$s'$ 的期望就是 $s$，所以 $f(s) + \lambda s$ 也满足所有方程，而各集合大小之和恒为 $N$，$\lambda$ 在答案里抵消。

   样例 $[2, 2]$（$N = 4$）：$s = 1$ 时 $s'$ 是 0 或 2，$\frac12 f(2) - f(1) = \frac14$，$f(2) = \frac12$；$s = 2$ 时 $P(k = 0) = \frac13$、$P(k = 2) = \frac23$，$\frac13 f(2) + \frac23 \bigl(\frac12 f(2) + \frac14 f(4)\bigr) - f(2) = \frac12$，$f(4) = 4$。答案 $4 - 2 \times \frac12 = 3$。

   > 期望轮数的本质：找一个每轮期望恰好加 1 的势能，期望轮数就是终局势能减开局势能。

   ```cpp
   #include <bits/stdc++.h>
   using namespace std;
   typedef long long ll;

   // L2 4.1 的 gauss（模质数）：把 P 改成 998244353，这里只放声明，实现照抄 L2
   const ll P = 998244353;
   ll qp(ll a, ll e);
   int gauss(vector<vector<ll>>& a, int m, vector<int>& where);

   int main() {
       ios::sync_with_stdio(false);
       cin.tie(nullptr);
       const int MX = 405;
       vector<ll> fact(MX), ifact(MX), pm(MX, 0), ip2(MX);
       fact[0] = 1;
       for (int i = 1; i < MX; i++) fact[i] = fact[i - 1] * i % P;
       ifact[MX - 1] = qp(fact[MX - 1], P - 2);
       for (int i = MX - 1; i > 0; i--) ifact[i - 1] = ifact[i] * i % P;
       pm[0] = 1;                                           // pm[x]：x 个点的完美匹配数
       for (int x = 2; x < MX; x += 2) pm[x] = pm[x - 2] * (x - 1) % P;
       ip2[0] = 1;
       for (int i = 1; i < MX; i++) ip2[i] = ip2[i - 1] * ((P + 1) / 2) % P;
       auto C = [&](int a, int b) -> ll { return fact[a] * ifact[b] % P * ifact[a - b] % P; };

       int t;
       cin >> t;
       while (t--) {
           int n, m;
           cin >> n >> m;
           vector<int> a(n);
           for (auto& x : a) cin >> x;
           int N = 2 * m;
           // 未知数 f(1..N) 在第 0..N-1 列，第 N 列是右端
           vector<vector<ll>> A(N, vector<ll>(N + 1, 0));
           A[0][0] = 1;                                     // 第 0 行：f(1) = 0
           ll invPm = qp(pm[N], P - 2), invN = qp(N, P - 2);
           for (int s = 1; s < N; s++) {                    // 第 s 行：E[f(s')] - f(s) = s / N
               for (int k = s % 2; k <= min(s, N - s); k += 2) {
                   ll p = C(s, k) * C(N - s, k) % P * fact[k] % P * pm[s - k] % P * pm[N - s - k] % P * invPm % P;
                   for (int j = 0; j <= k; j++) {           // s' = s - k + 2j，概率 C(k, j) / 2^k
                       int x = s - k + 2 * j;
                       if (x > 0) A[s][x - 1] = (A[s][x - 1] + p * C(k, j) % P * ip2[k]) % P;
                   }
               }
               A[s][s - 1] = (A[s][s - 1] + P - 1) % P;
               A[s][N] = s * invN % P;
           }
           vector<int> where;
           gauss(A, N, where);                              // 补了 f(1) = 0 后解唯一
           auto f = [&](int x) { return A[where[x - 1]][N]; };
           ll ans = f(N);
           for (int x : a) ans = (ans - f(x) + P) % P;
           cout << ans << '\n';
       }
   }
   ```

3. **复杂度和坑**
   - **复杂度**：$O(N^3)$，$N \le 400$。
   - **$f(0) = 0$ 不是未知数**：搬空的集合不在局面里，转移到 0 的那一项直接丢掉。
   - **少一个方程不是题出错了**：$f(s) + \lambda s$ 都是解，补 $f(1) = 0$ 定下来。
   - **配法按完美匹配数**：每轮所有元素一次配成 $m$ 对，不是每个元素各自挑伙伴，分母是 $p(N) = (N - 1)!!$。

> **看到“随机过程，求期望多少轮结束”时**
>
> - **先找每轮期望恰好加 1 的势能**：期望轮数 = 终局势能 − 开局势能，不用把整个局面当状态。
> - **势能按对象拆开**：每个对象的变化只依赖自己时，方程只剩对象大小这一维。
